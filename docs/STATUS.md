## 4. 发布前仍需完成

- 复核第一方权利归属、历史提交中的个人信息、名称使用及第三方对应源码的提供方式；
- 在干净 Windows 环境检查解压启动、运行库安装和高 DPI；当前主机已经安装开发运行库。
- 到设备旁完成真实串口、ADB 文件收发、Agent 部署/重连和维护回归；分别保留只读与写入验证结果。
- 真实 Windows 中文 IME、top/vi/menuconfig、物理拔线、重启启动日志和长时间高波特率未验证。
  本机模拟时延不能代表 UART 实机回显或全部主机上的流畅度。
- 录制无自动分卷或断电恢复保证；坏盘/网络目录可能延迟取消与关闭，flush 不等于硬件持久化。
- 文件替换、删除等操作仍可能与外部进程竞争，失败或停止后需要刷新复核；不宣称回滚。
- 维护门禁只约束本工具拥有的任务；Root/Remount 响应、ADB 上线或硬件字段读取完成均不代表设备验收通过。
