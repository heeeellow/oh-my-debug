## 2. 已实现

### 设备与连接

- 发现 Android/Linux ADB 设备，识别目标架构，按需部署、启动、连接、断开和版本切换。
- Android 连接核验 root 身份；Linux 部署核验清单、SHA-256、aarch64、glibc 与 root adbd。
- 设备信息包括型号、厂商、产品、CPU、内存、系统、内核、构建和安全状态。
- 设备连接应用服务负责重连、按需准备、握手、版本校验、能力发现、系统信息读取和失败清理；Qt 窗口只负责后台调度与界面映射。
- 空闲时每 2.5 秒静默检查 ADB 设备列表；列表未变化不刷新界面，插拔后保留当前选择且不自动切换到另一台设备，串口任务运行时暂停轮询。
- 内置 ADB 36.0.0 精简包，构建时复制至输出目录；`ADB_PATH` 覆盖仍优先，程序旁 ADB 优先于 SDK 和 PATH。
- “远程调试”页的“打开 ADB 终端 ↗”以固定设备序列号打开 Windows Terminal，无法启动时回退 cmd；无需 Agent，启动在后台完成，关闭应用不关闭外部终端；文件页不保留重复入口。契约见 [ADB 终端](features/ADB_TERMINAL.md)。
- 顶栏分别显示所选设备的 ADB 状态与调试服务的未连接、连接中、已连接、连接失败状态。已连接服务每 3 秒在独立后台连接上检查握手、版本和串口能力，单次套接字收发超时为 1500ms；失联后清除端口关联、断开使用该服务的串口通道并在后台清理转发，旧代次结果不能覆盖新连接。
- 设备侧 `testtools-agent`（v0.3.7）仅开放固定能力（系统信息查询、串口枚举与托管、只读硬件观察），不提供任意 shell RPC。

### 串口调试

- Windows 本地串口与设备串口支持连接、断开、文本/HEX 收发、行尾、TX/RX 显示、字节统计与一键“计数清零”（`SerialSession::resetCounters`）。
- 接收缓冲（`SerialLogBuffer`）按接收批次独立记录，不再按 250ms 窗口合并；原始字节不变，不完整 UTF-8 立即转义显示。TX/RX 颜色在文本、HEX 与过滤重绘中一致，具体显示规则见 [串口契约](features/SERIAL.md#44-监视器)。
- 收发记录支持动态切换 HEX/时间戳、自动滚动与日志导出；清空日志和计数清零保持独立，提示文字说明保留内容。
- 单串口模式将位置、串口、波特率与“刷新串口、更多参数、状态、连接”合并为同一行并限制下拉框最大宽度，释放纵向空间给收发记录窗口；发送框“清空”按钮移至发送输入框下方工具栏（与“定时 / 次数…”和“发送”同排），避免紧贴接收窗口正下方引起误解。
- 单串口模式提供可收起/展开的快捷指令栏，下拉框同时展示“名称 — 指令预览”，支持文本与 HEX 两种快捷指令格式、“填入输入”（填入下方发送框并同步 HEX 勾选）与“发送指令”（立即发送）；文本快捷指令与手动发送共用发送数据区唯一的行尾选项，单串口默认 CRLF。
- 串口界面偏好（`SerialPreferencesStore`，保存于本地应用数据目录 `serial-preferences.json`）支持按端点保存和恢复来源（单串口默认 Windows 本地串口）、端口、波特率、数据位、校验、停止位、流控、行尾、显示开关与快捷指令栏展开状态。
- 单串口为默认方式；双端方式提供双向验证和基于序号/CRC 的可靠性压测。
- 双端验证与压测结果移至两端工作区下方；压测结论和两个方向的统计分行展示，支持换行与复制。
- 普通定时/次数发送与可靠性压测保持独立参数、状态和结果。
- 增加 `230400 / 460800 / 1500000` 预设；按需搜索栏支持文本/HEX 字面量匹配、计数、上下跳转和只看匹配，缓冲截断可见。
- “指令库…”菜单支持 JSON 导入/导出；导入校验后替换，保留当前行尾，失败不改变原库。
- 本地 DTR/RTS 通过会话代次在后台设置，驱动拒绝会恢复原选择；硬件流控禁用手动 RTS，Agent 不支持时禁用。连接/重连不额外设置控制线。
- 串口连接、异步发送队列、计划发送和统计由无 Qt 会话层拥有，GUI 线程不等待设备数据通道退出。
- 新增“串口终端”，复用通道 B 的连接与计数；进入/连接后直接输入，历史、编辑与补全由板端处理。
  已取消终端底部命令框和常驻快捷指令/中断按钮；行尾、退格等辅助设置收进选项菜单，本地串口不依赖 ADB。
- 终端按连续 RX 解析跨批次 UTF-8/ANSI、行首覆盖和退格；修复纯光标序列不刷新的问题，支持闪烁光标、
  回看输出与复制时保持视图。键盘、搜索、时间戳和导出行为见
  [串口终端契约](features/SERIAL_TERMINAL.md)。普通监视器不恢复按时间合并。
- 手工输入端口名优先于旧选项隐藏数据，刷新保留手工输入；监视器将终端 Backspace 的 DEL 字节转义显示。
- 本地串口改用 RX 事件立即通知，修复小批量回显滞留、输入字符直到后续回车才显示的问题。
- 选用设备串口而调试服务未就绪时，串口页显示持续的行内原因和连接/重试入口；连接准备与旧连接清理期间禁用重试。通道自身的连接状态保持独立，本地 COM 不依赖调试服务。

### 界面

- 串口与 ADB 统一采用左侧二级导航；一级使用更明显的字重，二级缩进，当前父级与子级同时高亮，父级选中态弱于当前子级。串口展开单串口调试、双端调试、串口终端，父级恢复当前模式，箭头只收起/展开，页面顶部不重复放模式页签。活动任务与端点 A 占用的切换保护仍有效。
- 文件列表采用 UI 层模型/代理和可复用窗格，提供大小/类型/时间列、自然排序、两端筛选、目录历史/最近路径、键盘操作、复制路径及同目录刷新位置恢复；可进入 `/sdcard` 等目录链接，递归传输仍拒绝链接。本地使用 Windows 文件关联与文件夹/程序/快捷方式图标，设备端按日志、配置、文档、图像、音视频、脚本、库、压缩包、APK 等常见类别显示图标；独立异步提供器限批读取并缓存，未知类别保留标准回退，不为图标下载设备文件。
- 进入文件页自动刷新两端目录，设备端首次从 `/` 开始，按设备记住本次运行上次成功目录；保持筛选、同目录选择和滚动位置，不提交或覆盖正在编辑的地址。传输期间延后刷新，完成后恢复；切换设备不改变已开始批次的目标。
- 双栏拖放和资源管理器文件拖入设备栏接通既有固定目标传输；任务区可收起，显示等待/进行中/终态，失败重试沿用原设备、目录与冲突选择。
- 串口连接参数栏与接收/终端光标视图提取为独立组件，服务与发送状态机保持无 Qt；按钮以文字和少量熟悉的标准符号为主，不增加装饰图标。

- ADB 文件传输页提供本地/设备双栏、设备绝对目录输入、字面量筛选、多选文件/文件夹及手动上传下载，本地初始目录为实际桌面；无需 Agent。
  同名普通文件可明确覆盖，默认跳过，已有同名目录首版不合并。后台任务固定设备与路径，逐项记录结果，支持取消与暂存后替换；具体边界见 [文件传输契约](features/FILE_TRANSFER.md)。
- “远程调试”页集中提供独立的 ADB 终端与 Android 投屏操作；投屏突出开始/停止、电源键和 PNG 截图，其余按键收进“更多操作”，画面仍在独立 scrcpy 窗口中。
  进入页面不自动启动，切页保留会话；Esc 不隐藏内嵌控制区。
  投屏会话固定绑定启动设备，切换顶部选择不会迁移控制；关闭主窗口先在后台停止本工具创建的投屏。
  scrcpy 4.1 与依赖随包复制，复用统一 ADB，无需连接 Agent，具体行为见 [投屏契约](features/SCREEN_MIRROR.md)。

- 主导航为可展开的“串口调试”（单串口为启动默认页）、“ADB 调试”和底部“设备信息”。父级文字恢复本次运行上次子页并展开；箭头只收起/展开，保留当前页与任务。
- 顶栏保留设备、ADB 状态、调试服务状态和刷新；未连接服务可直接准备/重试，已连接时点击进入设备信息。终端入口统一放在“远程调试”页，不重复提供页面页签或设备信息按钮。
- 设备信息页保留连接、断开、重置、兼容性与硬件信息，普通文案不展示内部连接机制。
- 全局主题采用暖中性的浅灰白、深灰和克制的低饱和棕红，降低边框对比并使用 7–10px 圆角；成功状态仅使用小面积低饱和绿色。
- 自绘抗锯齿下拉箭头与复选框勾选图标，收发记录和文本框选中态固定为浅棕红底、石墨色文字；“清空 / 计数清零 / 保存日志…”使用带柔和边框的次级按钮。

## 4. 开放风险

- 文件首版不合并已有目录，也不跟随链接/重解析点；正在变化的日志没有一致性快照保证。提交阶段取消与替换可能竞争，需刷新复核目标；设备断线可能遗留本批临时目录。完整限制见文件功能契约。
- 现有投屏已传入 `--no-audio`，但与板端播放、录音及 AEC 等音频路径的共存尚未实机验证；用户历史 scrcpy/ARDC 差异及后续对照方案见 [ADR-0005](decisions/0005-adb-workspace-terminal-and-files.md)。
- 串口桥接仍需处理阻塞发送、短写、关闭边界、原始记录完整性和 GUI 接收队列上限。
- `MainWindow` 仍保存连接的界面状态和异步代次，`SerialWorkspace` 仍协调双端验证与可靠性压测；后续只在需要复用或独立验证时继续下沉。
- 历史代码仍混用 `serialdemo` 与 `testtools` 命名空间，应在独立机械重构中统一。
