# Oh My Debug 0.18.1 更新说明

[项目首页](../../README.md) · [使用手册](../USAGE.md) · [验证与交付状态](../STATUS.md)

本版包含自 0.16.0 之后的工具箱开发与反馈修复，桌面版本 0.18.1，配套 Agent 0.3.12，控制协议保持 1。
此页记录更新内容，实际提交、打包、发布及验证范围以 STATUS 为准。

## 新增与改进

- 新增“工具箱”，集中提供 GPIO 调试和以太网测速，保留独立参数、任务状态与报告。
- GPIO 支持离线管脚号双向换算、实际 Linux 号核对、占用者查看及可见页刷新；修复部分 Rockchip 4.19 固件的行信息兼容。
- 统一物理引脚、设备名称和用户备注，不需要选择访问来源或先加入常用。旧备注保留，已占用引脚保持保护。
- 按能力提供读取、输出保持、脉冲与输入监听；已适配的设备控制接口可在保持驱动占用的情况下读取或持续设置。两种输出的持续与释放效果明确说明。
- 网络测速支持 TCP/UDP、单向或顺序双向；无 IP 的物理网口仍可选择，开始前核对地址、链路和路由。
- 曲线分别保留双向采样，提供刻度、统计、悬停与放大波动。结果和报告区分已执行、失败与未执行方向。
- 网络地址与测试参数重新分组，时长框右边缘对齐；高级参数入口在顶部保持可见。数字框补齐上下箭头，支持手输、键盘与原范围限制。
- 设备维护按钮简化文字，新增可见的“进入 Loader”入口与只读支持识别；请求前复核当前设备，保留一次默认取消的确认。ADB 离线不等同于已进入 Loader。
- 随包增加固定版本 iperf3 Runner、Windows 配套运行库和 JSON 解析依赖；构建与打包按摘要校验文件。
- 第一方版权署名统一为陕西瑞迅电子信息技术有限公司，保留 Yanzhaohui 的开发者署名；发布包同时携带 Cygwin 3.6.5-1 对应源码及官方构建配方。

## 使用与验证边界

GPIO 和网络工具需要连接配套板端服务；Windows 本地串口与普通 ADB 功能保持独立。
GPIO 输出、输入监听、网络测速和设备维护会产生实际设备动作，仍需按页面确认目标、接线和参数。

本轮 Windows 核心与原生 UI 检查通过，并完成三档 DPI 与两块板卡的 GPIO/Loader 只读检查。
ZIP 完整性、配套工具与移除 SDK/PATH 的解压启动检查通过；确认 Qt/MSVC 运行库从包内加载。
真实 GPIO 输出、Loader 切换/恢复和全新 Windows 测试机仍未验证；详细范围与历史网络实测分开记录，见 STATUS。

本版采用 ZIP 便携包，完整解压后直接运行；Qt、MSVC 运行库和配套工具均随包提供。
当前发布状态、包路径和验证结果见源码仓库 STATUS。
单文件便携 EXE 是待实现的交付方式，不计入本版已完成功能。

## 已知问题

以下为代码审查发现的待改进路径，尚未进行实机故障注入复现：

- 同设备多实例使用时，退出清理可能影响其他实例的 Agent 转发；普通 ADB 命令的超时处理可能连带结束其启动的共享子进程。建议同一设备只由一个实例操作。
- GPIO 监听结束前若积压超过一批事件，报告可能没有取完剩余事件，不能据此认定高频记录完整。
- Agent 控制连接尚需补充连接数量与空闲期限限制。
