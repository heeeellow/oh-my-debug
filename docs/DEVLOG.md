# TestTools 开发日志

## 2026-08-28：工作台演进启动

### 目标

在不回归现有双端点串口能力的前提下，将单窗口 DEMO 演进为设备中心的调试工作台，并为板端
Agent 留出稳定边界。

### 基线事实

- Qt 界面、设备扫描、连接管理和串口测试集中在一个约 42 KB 的 `test.cpp` 中。
- 串口传输已经通过不依赖 Qt 的 `ISerialTransport` 抽象。
- Windows 串口使用 CSerialPort；板端串口使用 `adb forward ... dev:/dev/...`。
- 当前发布目录只有主程序，没有独立部署依赖集合。
- 当前工作区不是 Git 仓库，无法使用提交作为回退入口；修改前后必须依赖文件差异和构建产物核对。

### 设计决策

- 开发记录改为仓库内的架构、UI、开发手册和里程碑日志，不使用故障 Review 作为主体结构。
- 第一阶段实现固定布局的工作台外壳并拆分串口页面。
- 参考 Qlementine、Fluent-Qt 和 Qt Creator，但暂不引入第三方 UI 依赖。
- 板端 Agent 使用版本化、长度前缀协议；详细约束见 `ARCHITECTURE.md`。

### 当前验证

- 架构：已完成编码前自审，允许进入第一阶段实现。
- 分层：`core/` 与 `application/` 的 Qt 类型/头文件扫描无命中。
- 构建：Visual Studio 18 + Qt 6.11.2，`x64 Release` 全量重建通过。
- 核心自测：通过编码检查、ADB 在线设备枚举、3 个板端串口枚举及安全 `dev:/dev/null`
  转发创建/清理。
- UI 快照：概览页和串口工作台在 1440×900 逻辑窗口下通过人工视觉检查；未出现裁切、重叠
  或错误的操作层级。
- 实机串口：本轮没有在未知接线条件下打开 COM1 与 `/dev/ttyS2`，因此真实收发和双向回环仍是
  明确未覆盖项。

### 已完成实现

- 增加全局工作台外壳：设备选择、ADB/Agent 状态、固定导航和活动栏。
- 增加设备概览、测试中心、运行记录和设置页面骨架。
- 将原 `test.cpp` 串口能力拆为 `ui/pages/SerialWorkspace`，并移除页面内重复的板卡选择。
- 增加不依赖 Qt 的 `application/DeviceDiscovery`，UI 只负责异步调用和呈现。
- 增加集中式主题，设备下拉项优先显示易读型号，并保留完整信息提示。
- 增加可复现的 UI 页面快照入口，退出未使用的空白 `.ui/.qrc` 构建项。

### 当前开放项

- 在明确物理接线后完成 COM/板端串口真实收发和双向验证。
- 定义 Agent v1 的能力发现、心跳和任务状态最小消息集，并先实现假服务测试。
- 将设备会话、任务状态和历史记录从页面状态中继续下沉到 `application/`。

## 2026-08-28：轻量视觉修订

### 触发原因

首版工作台使用深色顶栏、大面积深色控制台、多个彩色胶囊状态和较重字重，功能层级清楚，
但视觉对比过强，呈现出模板化后台界面的感觉，不适合长时间调试使用。

### 调整内容

- 顶栏、导航和工作区改用相邻中性灰建立层级，移除深色顶栏。
- 概览的三个独立卡片合并为一个连续设备信息表面。
- 接收控制台改为低对比浅灰，仅保留一个低饱和蓝色主操作色。
- 状态从彩色胶囊改为文字色；端点 A/B 从彩色圆形徽标改为中性小方标。
- 字体调整为 Segoe UI Variable Text 优先，统一使用 400/500 字重，并重新定义标题、正文、
  辅助文字和等宽数据层级。
- 将状态样式从页面内联 QSS 收拢到集中主题，便于后续增加浅色/深色主题。
- 增加 `--ui-size` 快照参数，并修正可编辑波特率框起始字符被遮挡的问题。

### 验证

- `x64 Release` 全量重建通过。
- 底层自测通过：编码、ADB 设备枚举、3 个板端串口枚举及安全转发创建/清理。
- 1440×900 与 1366×768 逻辑窗口快照通过人工检查，无裁切、重叠和关键字段遮挡。
- 首次概览快照退出时出现过一次 `0xC0000005`，图片已正常生成；随后相同路径连续复测 3 次均
  正常退出，当前无法稳定复现，保留为退出时序观察项而不归因于视觉改动。
- 正文、辅助文字、状态色和主按钮关键组合按 WCAG 4.5:1 基线复核；禁用态和占位符不承载
  关键信息。
