# 清晰线性图标设计核对

[返回界面设计](../UI_DESIGN.md) · [当前验证与交付](../STATUS.md)

日期：2026-10-30。范围：桌面 0.12.1 的图标替换。

## 选定方向与实现

用户选择实际展示顺序中的第三组“清晰线性”，[参考图](../design/assets/icon-clear-linear-reference.png)为本轮视觉依据。
本轮在现有 Qt Widgets 页面内落地较清楚的线性轮廓、深灰操作、棕色强调、白色主动作与金黄色目录。
实际图形使用内置 Phosphor Bold，文件夹使用同库 Duotone；图形路径和许可来源见 [第三方依赖](../THIRD_PARTY.md)。
保留现有双栏、控件文字、快捷键与业务流程。参考图用于确认图标语言，不把图标展示板的放大尺寸、分隔线与排版加入产品页面。
开目录采用同库打开文件夹图形；压缩包采用 ZIP 文档图形。这些是同一风格内的惯用语义适配。

## 视觉与交互检查

参考图和实际应用资源生成的图标板在同一轮对照工具输入中查看；另逐张目检下列受影响样本。
本地证据位于 `build/iteration-0.12.1/`，表内 `evidence/` 指其 `native-tests/evidence/`。

| 样本 | 尺寸 / 实际 DPR | 核对与结果 |
| --- | --- | --- |
| `evidence/icons-clear-linear.png` 与 `icons-clear-linear-highdpi.png` | 1440×800 逻辑 / 1、1.5 | 放大轮廓与参考风格一致，主按钮为白色图标，普通/强调/禁用/已收藏状态可区分；高 DPI 轮廓清楚 |
| `evidence/files-empty-tasks.png` | 1366×768 / 1.25 | 导航、地址、金黄目录和设备日志图标对齐；收藏为实心星与“已收藏”，空任务区收起 |
| `evidence/files-narrow.png` | 1120×768 / 1.25 | 长路径、已收藏、上传禁用、下载启用与失败重试同屏；主动作和目录输入仍可使用，无图标覆盖文字 |
| `evidence/files-high-dpi.png` | 1366×768 / 1.5 | 工具栏图标与目录图标清楚，地址与收藏不挤压，表格和任务区保持对齐 |
| `evidence/files-permissions-dialog.png` | 440×541 / 1.25 | 勾选标记与数字输入清楚，权限矩阵对齐；未改权限行为 |
| `evidence/remote-file-types.png` | 模型专用样本 / 1.25 | 日志、压缩、图像、音频、视频、脚本、库、APK 分类均有内置图标；此样本只核对分类图形，不作为产品配色样本 |
| `deployed-serial.png` | 1366×768 / 1.25 | 刷新和清空与文件页一致，收发区及快捷侧栏未被新增图标挤压 |
| `deployed-mirror.png` | 1366×768 / 1.25 | 投屏开始、停止、保存截图采用同库线性图标，离线禁用状态可辨认 |

没有待修复的 P0/P1/P2 视觉问题。1120 逻辑宽度下本地表格保留横向滚动、长名称可能省略，符合现有列宽策略；标准支持窗口仍为 1366×768 起。
工具按钮的提示和可访问名称、收藏文字、列表类型列保留；状态同时通过形状或文字表示。

`related-tests.log` 的 6 项原生界面检查通过，覆盖图标资源/缓存/DPR、文件页与管理、Windows 本地关联图标、全局导航、独立串口页及录制回归。
`highdpi-ui.log` 另记录 DPR 1.5 的文件管理交互通过。截图不替代这些行为断言。

## 运行与边界

Debug / Release 构建通过。Release 输出含 Qt SVG DLL、SVG 图像插件及 Phosphor 许可；仅保留 Windows 路径的独立进程成功打开文件、串口、远程调试页并保存快照，见 `deployed-runtime.json`。
本轮未改变文件传输、权限命令、目录读取、串口收发或投屏协议；未访问开发板、未重新测量目录延迟，硬件与长时验收仍沿用 STATUS 所列边界。
本报告位于仓库 `docs/`，遵守项目文档归属规则。
