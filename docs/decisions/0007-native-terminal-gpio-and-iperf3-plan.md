# ADR-0007 原生串口终端与测试工具箱

[当前状态](../STATUS.md) · [架构](../ARCHITECTURE.md) · [终端契约](../features/SERIAL_TERMINAL.md) · [工具箱契约](../features/TOOLBOX.md)

日期：2026-11-02。状态：原生串口终端、GPIO 与网络测速已接入；验证范围见 [STATUS](../STATUS.md)。

## 背景

原有按行显示的终端难以处理备用屏幕、光标定位和高频连续输出。
GPIO 与以太网测试则需要固定参数、设备身份、资源互斥、停止确认和可导出的结果。

## 原生终端选型

采用 libvterm 解析终端数据，由 Qt 字符网格控件显示。libvterm 为纯 C 依赖，
封装与后台解析放在无 Qt 的应用层；`TerminalGridWidget` 负责绘制、选择、输入和滚动。

| 路线 | 取舍 |
| --- | --- |
| libvterm 与原生 Qt 网格 | 复用终端解析核心，继续使用现有桌面技术栈；绘制、选择、输入法和回看由项目实现 |
| xterm.js 与 WebView | 需要额外浏览器运行时和原生桥接，本项目未采用 |
| QTermWidget | Windows 接入与伪终端适配需要额外工作，本项目未采用 |
| 继续扩展旧文本控件 | 需自行补齐终端状态与屏幕管理，并承担文本重排开销，未继续采用 |

接收数据先进入录制路径，再交终端工作线程处理。UI 获取可见视口快照，按绘制预算合并更新，
不在 GUI 线程解析连续输出。回看和输入队列均有容量限制，空闲时不持续轮询。

复制、粘贴、中断、搜索和终端选项采用明确的键盘规则。多行粘贴先预览；普通串口发送与终端输入分开。
物理 UART 没有窗口尺寸的带外通道，调整窗口不自动发送 Shell 命令。

## GPIO 接口

板端通过 Linux GPIO 字符设备访问引脚，探测实际 ABI、节点和权限。
控制器身份与行偏移来自枚举结果，不通过传统 Linux 号推测设备路径。

读取保留原配置；输出、脉冲和输入监听具有明确参数与确认。输出任务有所有者、租约和释放流程，
重连不恢复旧输出。数字读回与软件定时不能代替外部电压、物理边沿或时序测量。

公司驱动接口的适配及统一展示分别见
[ADR-0008](0008-gpio-ownership-and-board-adapters-plan.md) 和
[ADR-0009](0009-unified-gpio-controls-and-maintenance-plan.md)。

## 网络测速

采用固定版本 iperf3。ADB 用于设备准备和控制，测试流量走明确选择的两端以太网接口与 IPv4 地址。
参数覆盖 TCP/UDP、方向、时长、并发流、UDP 速率和端口；地址、链路和参数在开始前复核。

桌面与板端分别管理自己的测试进程。任务使用实例身份、操作票据与固定资源，
启动响应丢失时查询原操作，避免重复启动。停止等待两端结束，结果未知时先复核再开始新任务。

双向顺序执行并分别保留采样和结果。原始输出有大小限制，截断须在报告中标明。
吞吐、丢包和抖动按实际协议与采样提供，界面曲线不补造缺失数据。

## 工程与分发

- 终端、串口、文件和工具箱分别拥有会话及结果，主窗口汇总任务状态。
- GPIO 与网络测试复用固定能力协议及资源互斥；Agent 不开放任意 Shell RPC。
- 工具与 Runner 按目标纳入 Bundle，部署时校验版本、文件大小、摘要和权限。
- 依赖版本、本地适配和许可记录在 [第三方说明](../THIRD_PARTY.md)，运行时不联网下载。
- 参数、协议与限额见 [工具箱契约](../features/TOOLBOX.md) 和 [协议文档](../AGENT_PROTOCOL_V1.md)。

## 后续范围

内嵌 ADB Shell、多标签终端和多板并发尚未实施。内嵌 Shell 需先验证 Windows 交互通道、
全屏程序、窗口尺寸同步和退出处理，不能直接复用普通命令执行器替代交互终端。

GPIO 电气状态、外部负载、网络实际流量及异常恢复分别进行实机验证；
主机测试、离线截图或参数解析结果不替代这些验证。
