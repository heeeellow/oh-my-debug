# ADR-0006 调试工作台交互与常用功能

[当前状态](../STATUS.md) · [产品设计](../PRODUCT.md) · [界面设计](../UI_DESIGN.md) · [架构](../ARCHITECTURE.md)

日期：2026-10-29。状态：分阶段实施，当前完成度见 [STATUS](../STATUS.md)。

## 背景

连接状态、串口记录、文件操作和设备维护分散在多个区域。串口记录缺少持续保存方式，
文件管理缺少常用目录和基本操作，维护结果与后台任务也需要更清楚的显示。

## 设计决定

界面继续使用 Qt Widgets 和暖中性配色。连接、看日志、发指令和传文件获得主要空间；
低频参数按需展开。一个区域只保留一个主要动作，禁用原因显示在操作附近。

| 工作 | 设计决定 | 现行说明 |
| --- | --- | --- |
| 设备栏与导航 | ADB 连接与板端服务状态分开显示，本地 COM 可独立使用；父级和子页选中状态清楚 | [界面设计](../UI_DESIGN.md) |
| 串口工作区 | 参数紧凑排列，接收区占主要空间；快捷指令位于可折叠侧栏 | [串口契约](../features/SERIAL.md) |
| 持续录制 | 显示缓冲与录制队列独立；支持带标记文本和原始接收字节，保存由后台线程完成 | [串口契约](../features/SERIAL.md) |
| 关键字高亮 | 只改变显示，不修改原始数据、录制内容或终端光标位置 | [终端契约](../features/SERIAL_TERMINAL.md) |
| 文件管理 | 增加目录收藏、历史、新建、改名、删除和权限编辑，与传输共用任务互斥检查 | [文件契约](../features/FILE_TRANSFER.md) |
| 远程调试 | 集中提供外部 Shell、日志导出、Root/Remount、重启和投屏控制 | [维护契约](../features/DEVICE_MAINTENANCE.md) |
| 设备信息 | 展示系统、内存、存储和读取状态，不加载规格文件或作合格判定 | [信息契约](../features/BOARD_INFO.md) |

## 任务与数据处理

持续录制在显示裁剪前接收数据，队列有容量限制。录制队列溢出时停止并说明文件不完整，
不能通过丢弃数据维持成功状态。停止录制后排空已接受数据，完成保存后才允许复用文件。

文件和维护任务在启动时固定设备与路径。取消不回滚已完成的文件操作；重启请求已经发出后，
停止等待不能表述为设备没有重启。关闭程序只清理自己创建的任务和进程。

板卡信息由固定只读能力提供，结果带设备、连接代次和读取时间。旧连接的回调不能更新新设备页面。
任务成功与观察值、硬件状态或规格符合性分别表达。

## 实施安排

1. 调整设备栏、导航和串口工作区，统一控件与状态显示。
2. 接入持续录制及关键字高亮。
3. 完善文件管理、日志导出和维护动作。
4. 接入板卡信息展示。

进一步拆分界面组件和优化吞吐按实际性能问题安排。后续终端与工具箱设计见
[ADR-0007](0007-native-terminal-gpio-and-iperf3-plan.md)。

## 验证要求

- 核心状态、参数与失败处理优先在无 Qt 层验证。
- 界面检查主要分辨率、DPI、键盘顺序、禁用原因和异步状态。
- 文件操作覆盖冲突、权限、断线、取消、目标变化和部分成功。
- 录制核对字节完整性、保存失败、队列溢出和退出处理。
- 维护与硬件验证记录实际设备、动作和结果，未执行项单独标明。

具体检查入口和记录方式见 [开发手册](../DEVELOPMENT.md)。
