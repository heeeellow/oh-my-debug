## 1. 背景与定位收敛

TestTools 当前聚焦于做好一款轻量、顺手的 **Rockchip 开发板与通用硬件调试工作台**，避免堆砌低频复杂功能。结合日常开发与排障的真实场景，确定以下核心边界：

1. **当 ADB 可正常连接时**：Windows 系统自带的终端（`Windows Terminal` / `cmd.exe`）已具备完整的全屏终端仿真能力，无需在应用内重复造轮子开发重型 ADB 终端，只需提供一键唤起系统终端并自动绑定内置 `adb.exe` 与当前设备序列号的快捷入口。
2. **当 ADB 无法连接时（U-Boot 阶段、内核 Panic、系统卡死、驱动未就绪）**：开发板的 **Debug 串口（如 RK 平台默认 `1500000` 波特率的 `ttyFIQ0`）** 是唯一的救命排障通道。普通串口助手的“填框点发送”模式不适合交互式 Shell 操作与海量彩色启动日志排查，因此需要在串口工作台中提供专门的 **「串口终端」** 模式。
3. **免环境依赖开箱即用**：内置打包精简 `platform-tools`（`adb.exe`、`AdbWinApi.dll`、`AdbWinUsbApi.dll`），优先调用内置 ADB；Windows USB 驱动由 RK 官方 `DriverAssitant` 负责，应用内不重复制作驱动安装器。
4. **后续视觉扩展（Android 投屏）**：仅面向 Android 端规划基于 `scrcpy` 的屏幕镜像与控制（复用内置 ADB），纯 Linux 端暂不纳入。

## 2. 本轮迭代范围与详细设计

本轮迭代分为四个内聚模块，全部围绕现有架构边界演进，不破坏“无 Qt 核心层”与“板端 Agent 无任意 shell RPC”的工程红线。

### 模块一：内置 ADB 打包与一键唤起系统 ADB 终端

1. **内置 `platform-tools` 集成与打包**
   - 将官方精简 `platform-tools` 三件套（`adb.exe`、`AdbWinApi.dll`、`AdbWinUsbApi.dll`）纳入仓库受控工具目录，并在 `TestTools.vcxproj` 构建后事件中自动同步至 `<OutDir>platform-tools\`。
   - 调整 [`resolveAdbProgram`](../../src/adapters/adb/adb_transport.cpp) 的查找优先级：
     1. 显式环境变量 `ADB_PATH`（便于开发期覆盖）；
     2. 程序同级目录 `<exeDir>\platform-tools\adb.exe`（默认开箱即用）；
     3. 系统环境变量 `ANDROID_SDK_ROOT` / `ANDROID_HOME` / `LOCALAPPDATA` / `PATH`。
2. **顶栏「ADB 终端」快捷按钮与兜底策略**
   - 在主窗口顶部设备栏新增 **「ADB 终端」** 按钮（仅在已选中在线 ADB 设备时可点击）。
   - **双层唤起策略**：
     1. 优先尝试拉起 `wt.exe`，使用统一解析的 ADB 路径与当前设备执行 `adb -s <serial> shell`；
     2. 若系统未安装 `wt.exe`、无法创建进程或启动器立即报错，自动回退新建 `cmd.exe` 窗口；保留窗口便于查看 Shell 退出信息。
   - 本模块的行为、打包和验收以 [ADB 终端契约](../features/ADB_TERMINAL.md) 为准。

### 模块二：串口调试三项高频补强

在不新增常驻面板的前提下，对现有串口工作台进行三项实用补强：

1. **RK 高速波特率预设与接收区搜索 / 过滤**
   - 波特率下拉列表补充 Rockchip 调试串口常用的 **`1500000`**（以及 `460800`、`230400`）预设项。
   - 在收发记录标题栏（`#terminalHeader`）右侧集成紧凑搜索框（支持 `Ctrl+F` 快捷键聚焦）、匹配计数、上下跳转及 **「仅看匹配」** 过滤开关。
   - 过滤仅作用于视图层（基于 `SerialLogBuffer` 按行筛选重绘），不修改或丢失底层已接收的原始数据，取消过滤立即恢复全量日志。
2. **快捷指令库 JSON 导入 / 导出**
   - 在快捷指令栏新增 **「导入…」** 与 **「导出…」** 动作，复用 `AtCommandLibrary` 的版本化 JSON 读写与边界校验能力，支持在不同模块（如 4G AT 指令集、Linux 常用调试命令集、MCU 协议指令集）之间快速切换或团队共享。
3. **本地串口 `DTR` / `RTS` 硬件控制线开关**
   - 在「更多参数」栏（或连接工具栏）增加 `DTR` 与 `RTS` 电平勾选开关，通过 `ISerialTransport` 透传至 Windows 本地串口（`EscapeCommFunction` / `DCB` 控制），满足需要拉高/拉低控制线唤醒模组或复位芯片的场景；板端 Agent 串口不支持时自动禁用并给出说明。

### 模块三：顶部切换栏新增「串口终端」模式（Debug 串口控制台）

将串口工作台顶部模式切换栏扩展为三项：
> **`[ 单串口调试 | 双端调试 | 串口终端 ]`**

1. **连接与会话无缝复用**
   - 「串口终端」与「单串口调试」共用同一个底层串口会话（`channels_[1]`）。若在单串口调试中已连接 COM 口，切入「串口终端」时**不断开连接**，直接切换视图与交互模式。
2. **专为 Debug 串口排障设计的交互体验**
   - **界面布局**：隐藏整个普通发送区和快捷指令栏，主区域用于直接键入的终端控制台；辅助设置集中于“终端选项…”菜单。
   - **实时按键与交互控制**：
     - 进入模式和连接后直接聚焦终端，按键透传，不另设命令框；
     - 支持 `Tab` 键发送 `\t` 触发板端 Shell 补全；
     - `Ctrl+C` 始终发送 `0x03`，由板端处理前台中断；`Ctrl+D` 发送 `0x04`、`Ctrl+L` 发送 `0x0C` 等待板端重绘；
     - `↑ / ↓` 发送方向键，命令历史由板端 Shell 管理；复制/粘贴使用 `Ctrl+Shift+C/V`；
     - 回车与退格格式通过菜单显式配置，不增加常驻发送按钮。
   - **ANSI 颜色与控制字符处理**：
     - 在无 Qt 的 `application/serial/` 层实现轻量 ANSI/VT100 流式解析器：正确处理 `\r`（行首覆盖）、`\b`（退格），并将常见的 ANSI SGR 颜色转义序列（如内核 `[  OK  ]` 绿色、报错红色、警告黄色）渲染为终端可读样式或干净剥离控制码，消除 `^[[32m` 乱码。
   - **启动日志排查联动**：
     - 复用关键字搜索、时间戳和日志保存；终端搜索只导航匹配，保留完整行布局，避免破坏光标映射。

根据首轮 Debug 串口反馈，交互收敛为直接输入，取消本地命令框与常驻辅助按钮，避免本地编辑状态
和板端行编辑器各维护一份历史与光标。普通串口助手继续保留填框发送和快捷指令。

模块三的输入、显示与兼容范围以 [串口终端契约](../features/SERIAL_TERMINAL.md) 为准，当前验证和交付状态见
[STATUS](../STATUS.md)。

### 模块四：Android 屏幕投屏与控制

- **范围**：仅针对 Android 开发板，基于 `scrcpy` 方案实现，与模块一共用内置 `platform-tools/adb.exe`。
- **能力**：独立窗口实时镜像、鼠标与键盘交互，以及控制面板中的电源、音量、返回、Home、多任务和 PNG 截图。
- 会话固定绑定启动设备，控制和截图不随顶部选择迁移；具体行为与验收以 [Android 投屏契约](../features/SCREEN_MIRROR.md) 为准。

## 3. 分阶段实施顺序

为控制单次改动规模并保证每一步均可独立编译、测试与验收，实施按以下顺序推进：

1. **Step 0：工作区清理与基线收敛**
   - 清理已废弃的历史设计文档、回退残留截图与 `build/` 下的临时审计目录；确认搁置模块的去留。
2. **Step 1：内置 ADB 打包 + 顶栏「ADB 终端」快捷拉起（含 `wt.exe` -> `cmd.exe` 兜底）**
   - 完成 `platform-tools` 打包、`resolveAdbProgram` 优先级调整与顶栏一键打开系统终端。
3. **Step 2：串口调试三项补强**
   - 完成 `1500000` 等波特率预设、`SerialLogBuffer` 搜索/过滤、快捷指令 JSON 导入/导出、本地串口 `DTR`/`RTS` 控制。
4. **Step 3：「串口终端」模式实现与验证**
   - 完成 ANSI/控制字符流式解析、三模式切换栏、终端按键交互（`Tab`/`Ctrl+C`/`↑↓` 历史）及 UI 快照与单元测试验收。
5. **Step 4（后续按需启动）：Android 屏幕投屏集成**
