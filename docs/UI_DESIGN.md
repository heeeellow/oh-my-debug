# TestTools 界面与交互设计

[返回项目首页](../README.md)

## 1. 设计方向

界面服务于长时间调试，应当安静、柔和、清楚。视觉以暖中性的浅灰白和深灰为基础，低饱和棕红只用于
当前选择、键盘焦点和主要动作。相邻表面优先依靠留白和很浅的边界分组，避免密集硬线条、高对比黑白、
蓝青紫渐变或科技风；绿色只用于小面积、低饱和的成功状态。

设计遵循以下规则：

- 先显示当前设备、任务状态和下一步，低频信息按需展开。
- 一个操作区最多一个实心主按钮，状态不能只依靠颜色表达。
- 普通流程使用任务语言，不展示内部组件、协议或验证工具名称。
- 固定布局优先，不引入装饰性动效、发光或多层卡片；圆角和间距用于缓解工具界面的紧张感。
- 错误说明对象、影响和下一步，原始技术信息不占据主界面。

## 2. 整体布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ TestTools  设备 [当前设备 ▼]  ADB 状态   调试服务状态      刷新设备 │
├────────────┬───────────────────────────────────────────────────────┤
│ 串口调试 ▾ │ 当前子页标题                                  │
│  单串口    │ 当前模式的连接、记录与发送区                        │
│  双端调试  │                                                       │
│  串口终端  │                                                       │
│ ADB 调试 ▾ │ ADB 子页标题     │
│  远程调试  │ 终端、诊断与维护，或本地 / 设备文件                   │
│  文件传输  │                                                       │
│ 设备信息   │                                                       │
├────────────┴───────────────────────────────────────────────────────┤
│ 活动  当前任务或最近操作                                  停止任务 │
└────────────────────────────────────────────────────────────────────┘
```

- 顶栏仅保存全局设备上下文，不放检查参数和维护细节。
- 顶栏按品牌、设备选择与紧邻的刷新、靠右的 ADB/板端服务状态和服务动作排列。按钮为“连接服务 / 服务详情 / 重试连接”；在线且可连接时使用棕色主动作，真实不可用时才变灰。显式准备期间显示实际步骤并禁用重复操作；后台只读探测保持连接按钮可用，点击可接管准备。状态标签使用无实体边框的圆点和文字。Windows 本地串口、文件、ADB 终端、投屏仍独立可用。
- 串口与 ADB 父级文字恢复上次子页并展开，首次分别进入单串口和远程调试；ADB 子项中远程调试排在文件传输上方。独立箭头只收起/展开，保留当前页和任务。
  子页占满内容区，不再放重复页签。“设备信息”放在导航底部。
- “打开 ADB 终端 ↗”只放在远程调试页的 ADB Shell 区，与 Android 投屏分别操作，文件页不保留此按钮。
  设备下拉框限制最大宽度，保证 1366×768 顶栏不拥挤。
- 文件传输和投屏会话各自固定启动设备；顶部切换不迁移已有任务，页面切换不自动开始或结束任务。
  关闭主窗口先停止发送任务，后台保存录制、取消传输并停止投屏，各自收敛后再退出；等待期间窗口仍处理事件。
- 一级功能组的文字和独立展开箭头处于同一个圆角行容器，整行统一悬停/选中背景，箭头采用抗锯齿 V 形图标。二级缩进更深、正常字重；当前子页用更明确的浅棕背景和左侧窄边。父级与子页同时选中，折叠父级不丢失选中态。
- 页面标题下最多一句说明；说明文字不能替代清晰的控件名称。
- 底栏保持单行，每条活动消息带本地时间 `[HH:mm:ss]`，完整消息可通过提示查看；右侧仅在有活动任务时显示入口，按实际快照汇总录制、计划发送、压测与传输任务。 无活动任务时隐藏全局任务入口。
  展开菜单显示对象、状态及明确停止动作；录制保存中禁用重复停止，停止单项不干扰其他任务或断开串口。

## 3. 页面结构

### 串口调试（启动默认页）

默认显示单串口调试；左侧“串口调试”展开单串口调试、双端调试、串口终端，顶部不再放模式页签。位置统一使用“PC端串口 / 设备串口”；刷新只扫描所选位置，PC 侧不要求板端服务，具体条件见串口契约。单串口模式下将位置、串口、波特率与“刷新串口、
更多参数、连接状态、连接”合并为同一行并限制下拉框最大宽度，将页面纵向空间优先让给收发记录终端。
收发记录标题行提供“HEX 显示、时间戳、自动滚动”与“计数清零、保存日志…、清空”；发送框的“清空”按钮
放在发送输入框下方工具栏（与“定时 / 次数…”和“发送”同排），避免紧贴接收窗口正下方造成误解。
单串口与终端去掉外层端点卡片的框线与内边距，连接栏横跨工作区；双端保留 A/B 卡片。
单串口右侧提供可调整宽度的快捷指令侧栏，列表逐项显示名称、预览、填入与发送动作。收起按钮位于侧栏顶部，
展开入口位于收发记录工具条；选择项目不会发送。文本快捷发送与手动发送共用唯一行尾控件。
侧栏默认宽度 240 逻辑像素，可调 220–480；窄屏自动收起，恢复宽度时按保存的偏好展开，手动收起保持关闭。
用户可显式展开或拖动宽度；自动适配不覆盖保存的偏好。可靠性测试仍属于双端调试的独立高级工具。

收发记录标题栏提供“搜索”按钮，展开紧凑的搜索行（查询、计数、上下跳转、仅看匹配、关闭），
默认隐藏；缓冲淘汰旧记录时显示“已截断”。保存与计数清零放在收发记录的“更多”菜单；空间不足时显示开关也移入该菜单。
指令管理、导入和导出位于侧栏“指令库”菜单。设备串口服务未就绪时，在各端点连接动作位置内联显示原因和连接/重试入口，保留日志区域高度。
标题栏同时保留“录制…”和可勾选的“高亮”。录制中显示“停止录制”与已写大小，保存中显示“正在保存…”，失败保留“录制失败 · 重试…”与具体原因提示。
窄窗口将显示开关移入更多菜单，仍能停止录制。高亮错误词为浅红底深红字，警告为浅黄底深黄字，搜索选区居于其上；详细规则由串口功能契约定义。
“更多参数”使用两行紧凑网格，DTR/RTS 与串口参数相邻，半选表示尚未手动设置；禁用时用提示说明原因。
双端模式同样使用“PC端串口”来源文案，并将 RX/TX 计数放在收发记录标题下的紧凑行，避免窄面板裁切。
日志 TX 使用棕色 `#965636`，RX 使用蓝绿色 `#286878`，状态提示使用中性灰 `#706963`，保留方向前缀。
接收区“清空”与“计数清零”保持独立，并通过提示说明保留计数或保留日志。
双端顶部只放链路与操作，双向验证和压测结果放在两端工作区下方的独立区域，字号 13px，支持复制与换行；
压测结论与两个方向分别成行，避免一条长文本被按钮挤压。

### 串口终端

左侧子项“串口终端”使用独立页面，复用连接栏组件；连接、参数、偏好和显示缓冲与单/双串口分开，切页保留各自任务，同口冲突指出占用页面。主区域显示连续板端输出，按 ANSI 样式渲染，不插入 TX/RX 前缀。
隐藏普通发送区、快捷指令栏和常驻显示开关；标题行提供录制、高亮、搜索、保存日志、清屏及“终端选项…”。
回车格式、Backspace、时间戳、跟随输出和计数清零放入选项菜单。进入页面和连接成功后聚焦终端，
直接键入，由板端回显、编辑、补全和管理历史，不提供第二个命令框。
Ctrl+C 始终中断，Ctrl+Shift+C/V 复制/粘贴；Ctrl+Shift+F 搜索时保留完整行布局。
滚轮和 Shift+PageUp/Down 用于本地回看，复制期间保持视图，继续输入回到实时光标。
详细键盘、显示与兼容范围见 [串口终端契约](features/SERIAL_TERMINAL.md)。

### ADB 调试：文件传输

本地与设备使用可调整宽度的左右双栏，顶部标题、路径行和文件列表对齐；文件列表优先获得纵向空间。
进入页面后台刷新，保留选择和位置；正在传输时延后刷新。路径草稿不被提交或覆盖。
本地初始打开实际桌面，可输入路径、选择目录、返回上一级和刷新。设备输入绝对目录后点击打开或按 Enter，
支持上一级、刷新和文件名字面量筛选；无在线设备时设备路径与操作禁用，本地仍可浏览。

Ctrl/Shift 多选文件或文件夹；双击目录进入，双击文件不启动编辑器。上传按钮位于本地栏下方，下载按钮位于
设备栏下方，旁边明确显示各自目标目录。输入路径改动、目录仍在加载、无选择或有活动传输时禁用收发。
同名处理默认跳过；普通文件可明确覆盖，已有目录首版跳过，不合并。具体边界见 [文件传输契约](features/FILE_TRANSFER.md)。

两端复用文件窗格和模型/代理列表，本地文件关联图标、统一目录图标和设备文件类别图标与名称、大小、类型、修改时间列对齐，支持排序、筛选、目录历史与位置恢复。下方任务区可收起，显示待处理、当前项及逐项结果，失败重试/取消与当前进度相邻；完整规则见文件契约。
条目摘要、已打开的目标目录与上传/下载按钮同排，长目标路径中间省略并保留完整提示。初始空任务区收起，首次文件任务自动展开，之后尊重手动折叠，状态栏保持单行。
标题栏只保留分栏名称与筛选，不重复列表右键操作。设备地址栏旁以“收藏/已收藏”直接切换当前目录收藏；地址下拉统一收藏、常用和最近访问，跨组去重，以图标、分组标题、行间距与选中样式区分层次。分组标题不可点击；通用目录图标在窗格内复用，内部重建下拉框不产生地址编辑通知，手工路径草稿保持明确的提交动作。删除确认固定对象、目录和名单，默认取消；权限弹窗固定设备、目录与选择，后台读取后展示实际值，支持勾选与八进制输入，多选不一致时不默认套用 755；结果列表区分每项状态。
不显示待写回标记、右键编辑入口或自动上传开关。

### ADB 调试：远程调试

页面宽度足够时采用左右两栏：左侧为 ADB Shell、诊断日志和设备维护卡片，右侧内嵌 Android 投屏控制；内容宽度不足 980 逻辑像素时上下排列并纵向滚动。投屏区域取消原先的 700px 最大宽度限制，切换布局保留会话。
日志提供 Logcat/dmesg 保存动作；维护提供 Root 与 Remount、重启，Loader 只在目标已确认支持时出现。维护确认框标明固定设备、动作与影响，默认取消；结果区保留原设备、实际步骤、部分完成、日志路径和按需展开的详情。进行中提供明确停止动作，底栏同步汇总，不根据最近活动消息推断任务状态。
终端是外部窗口启动动作，投屏保留独立画面；控制区显示当前选择/会话设备、状态和明确的开始/停止动作，突出电源和截图，返回、Home、多任务及音量收进“更多操作”。
进入页面不启动投屏，切页保留会话；Esc 不隐藏内嵌控制区。画面仍在独立 scrcpy 窗口中，便于与串口同时使用。
启动期间禁止重复操作，失败详情按需展开；切换顶部设备后仍清楚显示正在控制的原会话设备。
完整行为见 [投屏契约](features/SCREEN_MIRROR.md) 和 [设备维护契约](features/DEVICE_MAINTENANCE.md)。

### 设备信息

展示当前设备、Agent 连接状态、兼容性、型号、厂商、硬件资源、系统、构建信息、连接权限和可用功能。
设备连接与硬件/系统摘要采用响应式双列，内容宽度不足 980 逻辑像素时上下排列。内存仅在“硬件与系统”展示 GiB，提示保留精确 KiB 与系统可见容量的含义；存储容量与健康数据直接并入该卡片，进入页面且服务就绪后自动加载。
主界面以简洁属性行显示所有存储候选的类型和 GiB 容量，健康只说明数据是否可读取、是否缺字段，不另设大卡片、树状表格或重复设备节点。同一连接内切页保留结果，保留刷新、活动时的停止、更新时间和“存储详情”；全部字段、精确数值和原始结果放在详情。不放规格配置或合格判定。
停止与刷新同排，全局任务栏也可按任务 ID 停止。切换设备或服务代次时清除旧显示并等待新会话自动加载。完整规则见 [硬件信息契约](features/BOARD_INFO.md)。
主要动作是“连接板端服务”；“断开板端服务”和“重置板端服务”为次要维护动作。自动准备过程不在普通
文案中解释内部部署与转发机制。

## 4. 文字与密度

按钮以清楚的文字为主。文件类别保留必要图标，侧栏不加装饰图标；惯用操作配工具提示和可访问名称。辅助说明不用计数器底色或等宽字体。

操作与文件类别图标采用用户选定的第三组“清晰线性”，参考见 [选定样图](design/assets/icon-clear-linear-reference.png)。刷新、目录导航、上传下载、收藏、列表右键操作、日志保存/清空、投屏开始/停止/截图，以及展开箭头、复选框使用同一 Phosphor 图形体系，固定 SVG 随程序内置；实际图形和许可见 [第三方依赖](THIRD_PARTY.md)。图标替换沿用页面布局、文字和快捷键。

- 工具栏图标为 20 逻辑像素，点击目标尺寸保持原有约束；SVG 按实际 DPR 渲染并缓存，不能拉伸固定低分辨率位图。
- 普通操作使用深灰 `#423d39`，强调和已收藏使用 `#ad694e`，主按钮内为白色；禁用图标为 `#aaa29b`。已收藏同时保留实心星形与“已收藏”文字。
- 目录为金黄 `#e4aa32`；设备文件按类别使用线性文档图标，链接带链形标记。本地普通文件继续异步读取 Windows 关联图标，目录与查询失败的回退使用内置图标。
- 相同图标与色调复用句柄，设备图标和目录下拉不查询 Windows Shell，不下载设备文件内容。高 DPI 和代表页面的目检记录见 [图标设计核对](reviews/icon-style-design-qa.md)。

字体优先级：

```text
界面：Microsoft YaHei UI
数据：Cascadia Mono, Consolas, Microsoft YaHei UI
```

| 角色 | 字号 | 字重 |
| --- | --- | --- |
| 页面标题 | 20px | 600 |
| 区域标题 | 14px | 600 |
| 正文与控件 | 14px | 400 |
| 辅助文字 | 12px | 400/500 |
| 终端数据 | 13px | 400 |

常规控件高度 34–36px，目录工具按钮最低 30px。表格表头使用 12px/500，单元格上下内边距 6px，避免
稀疏的大行高。间距使用 `4 / 8 / 12 / 16 / 24px`，同组间距小于跨区域间距。

## 5. 颜色与控件状态

| Token | 色值 | 用途 |
| --- | --- | --- |
| `surface.app` | `#F7F6F4` | 应用背景 |
| `surface.panel` | `#FFFFFF` | 面板、输入、表格 |
| `surface.subtle` | `#F2F1EF` | 导航、终端、次级区域 |
| `border.subtle` | `#DEDAD5` | 分隔线与面板边界 |
| `border.control` | `#C7C1BB` | 输入和按钮边界 |
| `text.primary` | `#302F2D` | 标题、正文、输入值 |
| `text.secondary` | `#77716C` | 说明和次要标签 |
| `text.muted` | `#817A74` | 非关键信息 |
| `accent.default` | `#AD694E` | 主动作、选择、焦点 |
| `accent.hover` | `#995B43` | 主动作悬停 |
| `selection.soft` | `#F0E6E1` | 表格与模式选中背景 |
| `status.success` | `#5D715F` | 小面积成功文字 |
| `status.warning` | `#87652F` | 等待、风险、待核对 |
| `status.error` | `#A34A42` | 失败与危险动作 |

- 主按钮为低饱和棕红实心，次要按钮使用白色表面和柔和边界。
- 串口未连接时突出“连接”，连接后“断开”转为次级，普通调试的“发送”保持主动作；终端以直接键入为主。禁用态单独核对。
- 键盘焦点使用 2px 棕红边框，不依赖系统默认蓝色。
- 禁用态使用浅暖灰背景和仍可辨认的文字，不能仅降低到不可读透明度。
- 表格选中态为浅棕红色，选中文字保持石墨色；成功状态不使用大面积绿色底色。
- 文本框和收发记录的鼠标选中态同样使用浅棕红背景与石墨色文字，不继承系统白色选中文字。
- “清空”属于可见的次级动作，使用白色表面和柔和边界，不使用透明弱链接样式。
- 主要面板使用 10px 圆角，输入和按钮使用 7–8px 圆角；不使用渐变、重阴影、发光和高饱和装饰。

## 6. 文案与反馈

- 连接状态固定使用“未连接、正在连接、已连接、正在断开、连接失败、正在重连”。
- 检查结论固定使用“通过、不合格、待核对、执行失败、未执行”。
- 按钮包含动作对象，例如“连接设备”“发送指令”“管理指令”，不使用单独的“管理”或“确定”。
- 进行中动作使用“正在连接…”等文字；失败信息保留到处理完成或用户明确关闭。
- TX、RX、错误和状态同时使用文字与颜色，不以红绿作为唯一区分。
- 设备列表前台每 2.5 秒静默检查，后台降至 10 秒，回到前台立即补查；下拉选择期间不重建列表。
  未变化时不刷新模型、串口目标或服务连接，发现失败保留当前选择，恢复时修正状态；其他设备插入不触发当前设备重新连接。
  静默扫描和本地 COM 不禁用顶栏，维护和显式服务准备期间暂停发现；设备串口占用时仍保留目标保护。
  现有服务只在在线设备上下文改变或手动刷新时后台探测，缺失后不按轮询周期反复尝试；服务健康连续两次失败才置为失联，真实 ADB 离线仍立即处理。

## 7. 适配与验收

- 1366×768 下，顶栏、导航、页面主动作和底部活动区不得裁切；低频内容允许纵向滚动。
- 1920×1080 的额外空间优先分配给终端、项目表和详情，不拉长单个下拉框制造空洞。
- 支持 100%、125%、150% DPI，检查文字截断、表格行高、组合框箭头、焦点和禁用态；每批按 [开发手册第 5.2 节](DEVELOPMENT.md#52-按改动选择快照与回归) 选择受影响页面和代表组合，不要求全页面、全尺寸、全缩放重复抓图。
- Tab 顺序符合视觉顺序，所有交互控件有可见焦点，常规点击目标不小于 32×32 逻辑像素；目录导航工具按钮为 30×30。
- 页面切换不意外断开连接；退出能收敛后台任务和设备资源。
- 产品视觉验收范围包含串口、设备信息、文件传输、投屏控制和二级导航；具体批次检查实际受影响部分。暂缓入口不作为普通产品页面验收。
