# 使用说明

[返回项目首页](../README.md)

## 启动

解压整个 Windows x64 发布包，运行 `OhMyDebug.exe`。Qt DLL、`platforms/`、
`platform-tools/`、`scrcpy/` 和 `agent-bundle/` 应保留在程序旁。
如果 Windows 提示缺少 MSVC 运行库，先安装包中的 `vc_redist.x64.exe`。
本地开发或日常使用优先选择 Release；Debug 用于调试。

## 串口

普通收发使用“单串口调试”或“双端调试”；进入开发板 Debug Shell 使用“串口终端”。
选择 PC端串口、端口和波特率后连接。本地串口不依赖 ADB，也不需要先连接板端服务。
刷新会保留仍存在的选择；旧端口消失时按新发现结果更新，多个候选需要自行选择。

终端直接接收键盘输入，只显示设备回显。时间栏只标注收到文字的行。
“自动高亮”默认标记错误和警告，可关闭；字体、行距、配色和光标可在终端选项中调整。
默认 Ctrl+C 在有选区时复制，无选区时发送中断；多行粘贴会显示预览。

需要保存完整会话时先开启录制。清屏和显示裁剪不会删除已录制内容。
录制失败或断线的原因显示在连接区域，页面标题附近显示近期操作结果。

## ADB 与板端服务

通过 USB 连接并在设备上启用、授权 ADB 后，顶栏选择在线设备。
ADB 在线和板端服务在线是两种状态。文件、Shell 和投屏不要求先连接 Agent；
设备串口与硬件信息需要点击“连接服务”，按提示准备匹配的 Agent。
ADB Shell 仍使用系统终端，当前版本没有内嵌 ADB Shell。

文件页支持上传、下载和目录管理。写入、删除、Root/Remount 和重启可能改变设备，
请核对当前设备和界面确认内容；日志导出和硬件信息读取有独立入口。

## 设置与问题反馈

改名后继续使用 `%LOCALAPPDATA%/TestTools/`，原串口、终端和目录偏好无需迁移。
程序解压目录不保存个人设置。开发验证可通过 `TESTTOOLS_DATA_DIR` 指定独立目录。

报告问题时请提供版本、页面、操作步骤及相关日志；先去掉设备序列号、个人路径和业务数据。
当前验证范围及各功能契约请查看源码仓库中的 `docs/STATUS.md` 和 `docs/features/`。
