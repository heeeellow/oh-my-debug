# 文件传输功能契约

[返回产品设计](../PRODUCT.md) · [查看当前状态](../STATUS.md)

## 用户任务与入口

在“ADB 调试 → 文件传输”独立页面中浏览设备目录，将文件或文件夹下载到自选本地目录，或上传本地所选内容。
用途包括拉取日志、导出录音、上传资料，以及用户自行本地修改后的重新上传。传输复用统一 ADB，
不要求连接 Agent；Android/Linux 的实际可访问范围由当前 adbd 身份、文件权限、挂载状态和系统工具决定。

## 页面与选择

- 本地与设备目录分别维护：本地初始目录为 Windows 实际桌面，桌面不可解析时使用用户主目录；可输入路径、选择目录、前进/后退、返回上一级和刷新，最近路径在本次会话内保留至多 32 项。
- 设备目录由用户输入绝对路径并点击打开或按 Enter，也可以从现有终端 `pwd` 后复制粘贴；页面不推断终端目录。
- 双击普通目录和可达的目录链接进入，失效或不可达链接与特殊节点单独标识；链接可浏览不代表可以递归传输。目录访问拒绝、设备断线与路径无效保留各自错误，不自动提权。单项属性读取失败显示提示，不让整个目录消失。
- 本地端按需后台获取 Windows 原生文件关联图标，程序、快捷方式和文件夹可使用各自文件图标；一般类型图标缓存复用。板端按扩展名/常用类别提供文档、日志、配置、脚本、压缩包、图片、音频、视频、APK 和库文件图标，未知类型保留通用图标，不为图标下载文件内容。图标失败时立即保留标准回退，不阻塞目录列表。缩略图与云盘叠加标记不属于本轮范围。
- 两端列表提供名称、大小、类型、修改时间四列；支持目录优先、名称自然排序和按列排序，列宽可调整。两端均按文件名字面量、不区分大小写筛选，不筛选内容。Ctrl/Shift 多选，双击文件不启动编辑器；筛掉的选择不参与传输。
- Enter 进入当前目录项，F5 刷新，文件列表内 Backspace 返回上一级，Alt+Left/Right 前进后退，Ctrl+A 全选；列表菜单可复制完整路径。刷新同一目录按名称恢复可见选择和滚动位置，目录内容变化时仅恢复仍存在的项目。
- 双栏间拖放等同手动收发，目标为对侧当前已打开目录；本地文件或文件夹也可从资源管理器拖入设备栏。外部拖入的项目必须来自同一个父目录，先在后台校验源列表与固定目标；跨父目录需分批拖入。不提供拖出到资源管理器下载，APK 在文件栏只作上传。
- 上传的目标是当前已打开设备目录，下载的目标是当前已打开本地目录。输入框改动后，需要先重新打开目录才启用收发，避免显示目录与实际目标不一致。
- 不维护待写回状态、编辑会话或自动上传；文件传输不自动安装 APK、重载配置或重启设备。

## 进入页面与刷新

- 进入文件页后自动在后台刷新本地目录与当前设备目录；首次进入在线设备打开 `/`，后续使用该设备本次会话最后成功打开的路径。不同设备分别保留路径，旧设备的目录回调不得覆盖新设备。
- 刷新保留可恢复的选择、筛选与滚动位置。地址栏有尚未打开的新输入时，后台刷新已打开目录，不提交或覆盖新输入；收发仍以地址栏和已加载目录一致为前提。
- 正在传输时延后进入页面引起的刷新，批次结束后刷新；快速切页或已有加载时合并等待，不通过重建整个列表清空界面。
- 无设备/离线时仍刷新本地已打开目录，不执行远端刷新，显示设备要求；权限和目录错误可见，仍保留手动打开、刷新和 F5 恢复入口。自动刷新只发生在进入、设备变化和传输结束，不是持续目录监控。

## 传输、冲突与结果

- 同时执行一个批次，每批选择 1–256 项；任务启动时固定设备、方向和两个目标目录。切页保留任务，顶部切换设备不会迁移活动任务；读取目录的旧结果不得覆盖新设备界面。
- 对同名项目提供覆盖普通文件、跳过、取消选择，默认跳过。已有同名文件夹首版跳过，不合并、删除或整体替换；链接与特殊文件不覆盖。
- 文件夹保留其名称和内部结构。首版拒绝软链接、Windows 重解析点和特殊文件（含重解析点形式的云盘占位项）；递归最多 32 层、20000 项，下载文件名必须适用于 Windows，同一目录内不允许 Windows 无法区分的大小写重名。目录列表也有 20000 项及 4 MiB 命令输出限额，超限明确失败，不展示为完整结果。
- 下载先进入目标目录所在文件系统的新建私有临时目录，ADB 成功后才放到最终位置；失败或取消只清理本批创建的临时目录，保留原目标。
- 上传先进入设备目标目录下的新建私有临时目录，显式建立目录结构以保留 ADB 可能忽略的空目录。普通文件覆盖前复制原属主、权限以及可读取的 SELinux 标签，再执行同文件系统替换；属性设置、暂存或替换失败不报告成功。
- 上传需要目录创建和替换权限，以及设备 `stat/printf/mkdir/mv` 等固定工具；覆盖可能需要 `chown/chmod/chcon` 权限。只读分区、SELinux 拒绝及工具不支持时显示错误，不自动 root、remount、修改 SELinux 或提供任意 shell RPC。
- 进度包含当前设备、项目、已处理项数，以及 ADB 的当前输出；不把它当作精确总字节进度。单次目录/属性/目录创建命令超时 10 秒、单次 push/pull 超时 10 分钟、替换超时 10 秒、清理超时 3 秒；递归预检和目录建立由多次有界命令组成，可取消。
- 取消只终止本工具创建的 ADB 客户端，不重启共享 ADB server；已完成项保留，未开始项标为取消。提交阶段取消可能与替换完成竞争，需要复核目标，不宣称回滚已完成写入。设备断线导致临时目录清理失败时，可能留下 `.testtools-upload-*` 目录。
- 全局底栏按传输快照显示当前设备与批次进度，提供单独“取消传输”；取消入口核对批次 ID，旧菜单动作不得取消随后启动的新批次，也不停止串口录制或发送任务。
- 每项分别记录完成、跳过、失败或取消；批次汇总保留各项计数，部分成功不能显示为全部成功。底部任务区可收起，显示当前批次等待中、进行中与逐项终态，并保留最近 500 条会话内记录；双击完成记录可查看设备和完整路径。仅失败项可重试，重试沿用原设备、目录和同名策略，选择其他设备时禁用；取消项需重新选择传输。无永久传输历史库。

文件复制成功只证明传输与目标操作完成，不证明配置已被服务加载。正在变化的日志不提供一致性快照保证；
传输保持实际字节，不自动转码、转换换行或补齐日志内容。

## 分层与验收

`FileTransferService` 在无 Qt 层管理固定目标、批次、取消、结果与进度快照；固定 ADB 文件操作在适配器中实现。
Qt 只拥有文件列表、选择、确认与后台调度。Agent 协议和串口路径不变。

必要验收包括：普通文件和文件夹双向收发、空目录与中文/空格路径、同名文件和文件夹、权限失败、取消、
断线、设备切换和关闭；核心层检查批次目标固定及部分失败。界面检查 1366×768、1920×1080 和控件状态，
假后端、原生 ADB 夹具与真实板卡结果分别记录在 STATUS，不相互替代。

进入与切页检查首次根目录、按设备恢复目录、自动刷新保留筛选/选择/位置与未提交地址、离线本地刷新；传输期间延后，
旧设备批次结束后刷新新设备，不改变已开始任务的目标。图标检查本地文件关联与板端常见类别、异步替换、
查询失败回退和缓存复用；不能以截图替代后台线程与异常路径检查。
