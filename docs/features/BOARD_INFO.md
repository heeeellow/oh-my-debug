# 板卡硬件信息功能契约

[返回产品设计](../PRODUCT.md) · [查看当前状态](../STATUS.md)

## 范围与入口

“设备信息”作为只读看板，分别显示设备连接与硬件/系统摘要；存储容量与健康数据直接并入“硬件与系统”，不另设大卡片或主表格。
页面仅展示信息，不加载板型规格、不做阈值比较、不显示合格结论。
历史 Board Profile 评估器保留，未接入当前页面，也不随此功能新增配置包。
第四阶段暂不开展，先由用户集中体验已完成的功能。

连接与系统摘要宽度足够时左右排列，内容宽度不足 980 逻辑像素时上下排列，允许纵向滚动。
进入页面且当前服务已就绪时自动按存储信息、存储健康的顺序加载；先进入页面再连接服务时，在服务就绪后加载。
同一服务会话内切页保留已有结果，不重复执行；“刷新”显式更新，完成后显示更新时间。主界面逐项显示存储类型与 GiB 容量，健康只说明数据是否读到、是否缺字段，不显示健康判定。
“存储详情”按需打开全部属性、精确字节、原始寿命字段和 I/O 计数，原始协议数据放在详情中的独立页签。
后台页面不主动读取；切换设备/服务代次后清除旧数据，新会话可见时重新自动加载。维护或旧任务尚未收尾时延后加载。
仅请求当前服务明确声明的存储能力，未提供的项目说明不可用；不因进入看板而自动部署服务或请求 Root。

## 信息与含义

| 能力 | 展示内容 | 显示边界 |
| --- | --- | --- |
| `system.info` 的内存摘要 | “硬件与系统”中的 MemTotal 显示 GiB，悬停提示精确 KiB | 系统可见内存，不当作 DDR 标称容量或合格范围；不再重复发起 `memory.capacity` 任务 |
| `storage.device.info` | 主界面逐项显示 eMMC/UFS 与 GiB 容量，详情保留设备键、精确字节、内核名称、厂商、型号、序列号、固件 | 不自行选定“主存储”或忽略多个候选 |
| `storage.device.health` | 主界面显示数据读取情况，详情按设备键展示 Pre-EOL、寿命字段 A/B、可读取的累计读/写/丢弃字节 | 保留设备分档原值，不推算剩余寿命百分比；计数不是当前速率 |

只访问 Agent 已有的 `/proc`、`/sys` Provider；不运行压力测试、不写文件、不执行 ADB Shell 测试命令。
缺失、`null` 或无效字段显示“未知”；确实报告的数字 0 仍显示 0，不与缺失混淆。
“读取完成”只表示任务完成，不表示设备合格。失败、取消和超时分别显示，失败项保留原因，其他已完成项不丢弃。
详情中的“原始数据”提供当前存储任务的设备、任务 ID、Provider、schema、原始观察值、摘要和日志，可复制文本。

## 会话与执行

`BoardInfoService` 保留三个固定只读信息项的编排与解码，看板仅使用存储信息和健康两项，复用 `BoardTestJobClient` 的 `job.start/status/cancel`。
设备、连接代次、能力列表在开始时固定。实际桌面任务在后台创建并校验独立控制连接，
不与主窗口重连/关闭共用请求 socket；结束只关闭所属连接。

- 全局一次一个硬件信息批次，板端仍执行全局单板级任务约束；下一项前先保留前一项终态。
- 每项默认主机等待 10 秒，轮询间隔 80 毫秒；超时请求取消，停止后最多继续等待 3 秒确认终态。单次 RPC 的实际超时仍受控制连接实现限制。
- 响应必须对应原任务 ID、能力 ID 和已支持版本，观察值按已知 schema 解码；任务关联不匹配或传输异常会停止后续项。单项数据格式不支持显示读取失败，保留原始结果，不清除其他项。
- 取消只针对当前任务 ID，不继续发起后续项；取消与完成竞争时保留 Agent 实际终态，不将已经读取完成改成未执行。
- 停止回复或终态未确认时明确显示结束状态未知，不宣称远端线程已结束。当前有效会话的该状态仍阻止同设备维护；可重试读取或断开重连恢复确认，不向新连接发送旧任务的取消 ID。
- 切换设备、断开、失联或重连使旧会话失效并停止旧队列；旧结果不显示为当前设备/新会话数据，原任务仍按其原设备身份收尾。
- 与同设备 Root/Remount/重启互斥；重置服务也需先结束读取。Windows 本地串口独立工作。
- 页面和全局任务菜单提供停止，旧菜单 ID 不取消新批次。退出先取消并异步等待所属后台任务收尾。

编排和解码不依赖 Qt；Qt 只处理布局、输入、后台调度、轮询和显示。
不改变 Agent 能力、程序版本或协议，不开展第四阶段的通用协调器拆分与吞吐重构。

## 验收

核心覆盖固定顺序、能力门禁、同会话重读、精确单位、多个存储候选、0 与未知、任务互斥、旧 ID、
超时/取消/完成竞争、响应关联、失联/代次失效、独立连接创建/失败/关闭。
界面覆盖可见时自动加载、隐藏页不执行、同会话切页缓存、显式刷新、不重复内存任务、原始结果、失败原因、切换设备旧结果隔离、维护互斥、标准/窄窗/高 DPI 和活动任务退出。
实机、假连接、原生界面和构建分别记录在 STATUS；未连接真实设备时不以夹具数据替代实机结果。
