# 工具箱契约

[返回产品说明](../PRODUCT.md) · [协议](../AGENT_PROTOCOL_V1.md) · [验证与交付](../STATUS.md)

本页是 GPIO 调试和网络测速的行为依据。最初方案及取舍见
[ADR-0007](../decisions/0007-native-terminal-gpio-and-iperf3-plan.md)，实际验证范围只记在 STATUS。

## 导航与任务

一级“工具箱”下为“GPIO 调试”和“网络测速”，首次打开 GPIO，父级恢复本次运行上次子页。
进入页面只在服务已就绪时后台读取元数据，不自动部署、配置引脚或发起测速。
服务缺失、能力缺失、权限不足和接口不可用分别提示。

两页各自保留参数和最后结果；一次只允许一个工具任务，短时电平读取也占任务位。
任务固定启动设备、服务实例、所有者、操作标识和参数。切页继续执行；顶部换设备不会迁移任务，
结果显示原任务对象，旧回调不能覆盖新设备的元数据。工具与板卡信息共用 Agent 单任务限制。
同设备服务部署/断开/重置、Root、Remount、重启在工具活动或结束未知时禁用；本地 COM 独立使用。

停止请求与资源已释放是不同状态。后台每秒续租，板端租约 5 秒，进度读取不续租。
正常期限独立于租约；过期、取消或失联后释放本任务的句柄和子进程，不自动重跑。
停止或到期后未取得终态则显示“结束状态未知”，阻止新工具和同设备维护；重新连接原设备后
“复核结束”先废弃原操作，再核对原实例和任务。服务实例已变化时旧进程资源视为已退出，
原操作仍记为失败，不能补写成成功。板卡休眠期间不能承诺用户态及时清理。

## GPIO 调试

通用接口使用 Linux GPIO 字符设备，优先 ABI v2。新版只读探测返回 ENOTTY，或 Rockchip 4.19 固件对未知 ioctl 返回 EINVAL 时，再用 v1 查询验证兼容性；v1 也失败则保留错误。
权限拒绝不会触发绕过权限的回退。不依赖 sysfs export 或板端命令工具。

列表分页展示控制器、名称、行偏移、方向、active-low、驱动方式、占用和占用者。
枚举不请求行句柄、不读取电平。Rockchip 名称定位先换算 bank/offset，再核对控制器标签；
不假定 gpiochip 编号等于 bank。无法唯一确认时要求手动选择。
新增离线双向计算：`GPIO3_B4 ↔ 108`，显示 bank×32+组×8+位和行偏移。
算术 Rockchip 编号与 Linux 全局号分别显示；后者仅在 sysfs 控制器真实设备、标签和行数都匹配后用基址+offset 计算，缺失时显示未知。
例如 PMIC 的 gpiochip5 offset 0 可以是 Linux gpio-511，不能按控制器序号算成 160。
GPIO 页可见时每 3 秒后台更新占用，未变化不重建列表；保留筛选、选择与滚动位置，任务结束后补查。
占用为内核行信息快照，空 consumer 仍显示已占用，不当成空闲；最终申请由内核裁决。
常用引脚按设备和控制器身份保存备注；收藏只用于定位，不是控制门槛，也不自动恢复配置。

| 动作 | 参数与行为 |
| --- | --- |
| 读取电平 | as-is 短时独占读取，保持原方向/极性/驱动；已占用则拒绝，不抢占，也不改为输入 |
| 保持输出 | 指定物理高/低，初值随输出申请提交；保持 1–300 秒，默认 30 秒，结束释放句柄 |
| 延长保持 | 仅原活动输出任务可用，显式将剩余时长重设为 1–300 秒，不改变电平 |
| 单次脉冲 | 前后空闲电平与脉冲电平必须相反；10–10000 ms，默认 100 ms；正常或取消时尽力回到空闲电平，再释放 |
| 切换输入并监听 | rising/falling/both，1–300 秒，默认 10 秒；这是配置动作，不能视为只读 |

通用接口选择未占用引脚即可控制，无需加入常用；首次执行当前设备/连接/操作/参数组合时显示确认，默认取消。
修改参数或重新连接后重新确认。普通界面仅开放推挽；开漏/开源未完成电气验证，不提供选择。
输入偏置调整不提供。执行前重新检查占用，实际句柄申请仍由内核裁决。

结果区分逻辑值、active-low 和换算的物理数字状态；数字读回不能证明电压、负载或外部接线。
释放只说明句柄关闭，不承诺释放后的电平、方向或原配置恢复。监听记录内核时间戳和逻辑边沿；
v2 检查事件序号缺口，v1 无法证明内核无丢失，保留时钟与丢失检测限制。
板端事件队列最多 4096 条，单批最多 256 条；缺口或溢出标记不完整。脉冲为软件定时，
不承诺实时精度；异常路径保留实际步骤，不宣称回滚。

### 设备提供的控制接口

GPIO 页面只有一份引脚列表，不要求选择底层访问来源。设备名称、真实管脚、Linux 号和备注关联同一对象。
未占用引脚使用字符设备；已占用引脚仅在存在唯一且已适配的控制接口时按能力读取或设置，保留内核实际占用者。
多个接口映射不明确时禁止操作，不试写或自动切换写入途径。未关联的接口单独显示，不按名称序号猜管脚。
旧字符设备与接口收藏键关联到同一物理行；不同备注同时保留，移出常用时清除这行全部关联键，不影响其他引脚。
搜索包含原名称、设备别名和用户备注；刷新、查找和收藏均不发送 GPIO 写入。
驱动、路径与适配方式放在引脚详情。保持输出明确时长与释放；设置输出明确持续生效及不自动恢复。

当前固定适配两类驱动 ABI：

| 适配 | 发现依据与位置 | 命令语义 |
| --- | --- | --- |
| `rocktech-gpio/v1` | platform 驱动 `rocktech_gpio` / compatible `fsl,rocktech_gpio`，或 `gpio-control` / `rocktech,gpio-control`；设备树子节点 label/gpios 关联 `/sys/class/rock_gpio/<label>/value` | 读回物理数字值 0/1；输出低写 `10`、输出高写 `11` |
| `rk-gpio/v1` | platform 驱动与 compatible 均为 `rk_gpio`；设备目录中 `gpio0…gpio5` 分别关联设备树属性 `gpio1…gpio6` | 同上；UI 名称按设备树属性，属性序号收入详情 |

匹配基于已核对的 BSP 源码和节点格式，不按商品名或包含 gpio 的路径开放写入。
platform 设备名称可以不同；新增目录格式或驱动协议需增加受信任适配，不接受任意路径、shell 或未知属性写入。
两类驱动写 `0` 实际是切输入，写 `1` 不是有效的输出命令；这两类驱动仅提供读取和设置物理输出，不发送切输入命令。
设备树 flags 不用于反转该 ABI 的原始物理值。不同固件沿用相同标识但修改协议时，需重新核对适配。

发现只读元数据，不读取 value。端点 ID 由当前 Agent 内部签发；正常刷新保持 ID，节点/驱动/设备树绑定身份变化后旧 ID 失效。
通过真实控制器设备树 phandle、`#gpio-cells=2`、行偏移及原生行信息确认映射；空 consumer 或其他占用者不视为对应驱动已成功申请。
控制前重新发现并核对固定适配、节点/父目录身份和实际占用者，不关闭他人的句柄或解绑驱动。

- 已匹配节点可在权限允许时读取，即使字符设备行已被驱动占用；读取不改变方向。
- 首期仅为 `gpio1…gpio999` 形式的通用别名开放设置，且必须唯一映射、consumer 与别名一致并具有读写权限。
  其他命名用途（如 `sim_det`、`otg_drv_vbus`）、映射不明、重复关联或占用者不符均只读，并显示原因。
  通用别名不证明外部接线适合改变电平，操作仍固定设备、真实管脚、电平和可选备注进行确认。
- 设置把界面物理电平 0/1 转成 `10\n` / `11\n`，会切换为输出；一次写入后读取电平并复核输出方向/身份。
  驱动可能忽略内部 GPIO 错误，因此写入字节数成功不能直接算设置成功。
- 设置结束或程序退出后仍可能保持，不提供保持时长、脉冲、输入监听、解除占用或自动恢复；对应驱动继续拥有管脚。
  停止只停止后续步骤，不撤销已发生的写入；服务实例变化也不能当作硬件恢复。
- 工具内部沿用单板任务互斥、所有者/操作票据和租约。它不能排除其他程序或驱动自身同时写入 sysfs，读回只代表核对时刻。

报告保留端点、适配、技术路径、原始映射、设置前值、目标物理值、驱动命令、写入尝试/完成、读回与方向核对。
写入后读回失败仍记录写入已提交；响应丢失先复核原操作，不换票据重写。实际外部电压与接线需另行测量。
扩展接口缺失、旧服务或发现错误不影响字符设备 GPIO 和网络工具；权限不足不自动 Root、chmod 或换路径绕过。

## 网络测速

ADB 只承载控制与部署；测试流量走用户选择的两端以太网 IPv4，不经过 ADB 转发。
参数区两端地址各占一行；方向、协议与每方向时长分组为同一行，时长框右边缘对齐地址框；高级数字项紧凑分组，入口位于顶部工具栏，始终完整可见。
枚举并允许选择全部物理以太网接口，包括无 IPv4、链路未连接或已停用的网口，列表标明原因。
回环、Wi-Fi 和虚拟接口不作为以太网候选；保留接口身份，地址配置或变化后刷新仍选择同一网口。
开始前重新核对地址和两端路由，要求经所选接口。缺少有效网口、地址或配套工具时禁止开始。

| 参数 | 约束 |
| --- | --- |
| 方向 | 电脑到板卡、板卡到电脑、依次两个方向；默认依次双向 |
| 协议 | TCP 默认；UDP 为显式选择 |
| 时长 | 每方向 1–60 秒，默认 10 秒；紧凑数字框显示“10 秒”，支持增减箭头、手输与上下键 |
| TCP 并发 | 1–8，默认 1 |
| UDP 速率 | 1–1000 Mbps，默认 10 Mbps，只允许 1 流 |
| 端口 | 5201–5210，默认 5201；不自动关闭外部占用者 |

固定随包 iperf3 3.20，无自定义命令或参数透传，不运行时下载。
板端绑定所选地址启动单次服务，核对所属子进程的监听 socket 后才通知就绪，禁止用 TCP 预连接探测。
电脑客户端绑定所选源地址；反向使用同一控制连接建立的测试会话。输出对端与所选地址不符则失败。
清理只操作自己拥有的进程，不按名称杀进程或按端口清理他人程序。
前一方向成功收尾后才启动下一方向；取消、失败、断线后保留已完成结果，其余明确记为“未执行”。

曲线来自每 0.5 秒的实际流式采样，后台保留每批中的全部采样，而非只保留最近值；每方向最多 512 点。
双向使用独立图例、曲线与采样点，前一方向不因时间归零而清除。显示坐标刻度、当前值、平均/最小/最大值，支持悬停读数。
默认纵轴从零开始；“放大波动”显式按实际范围调整纵轴，刻度保留，稳定吞吐可以显示为近似水平线。
每方向报告保留 samples（elapsed_ms/bps），最终界面可从报告恢复完整曲线。结果分别保留发送/接收吞吐、
TCP 重传或 UDP 抖动/丢包，以及来源提供的 CPU 信息；缺失字段显示未知，不补零。
CPU 使用 `local_cpu_permille/remote_cpu_permille`：客户端记录的 local 是电脑，板端服务记录的 local 是板卡，不能仅按发送方向或 client/server 字样推断。
链路速率是背景信息，测速结果不直接判定硬件合格。
JSON 解析独立支持小数，控制协议仍只使用整数：bps、微秒、ppm、CPU 千分比，按最近整数舍入。
单条 JSON 最多 256 KiB，累计 stdout 最多 8 MiB；损坏或超限停止且保留失败原因。

## 偏好与报告

工具参数、网口身份/地址、GPIO 常用引脚和备注按设备后台保存至
`%LOCALAPPDATA%/TestTools/toolbox-preferences.json`。恢复参数不启动操作；网口不再存在时要求重选。
异步写入只保留最新待写快照，退出等待保存完成。测试可用
`TESTTOOLS_TOOLBOX_PREFERENCES_DIRECTORY` 隔离偏好目录。

结束后可导出 JSON 或文本报告，后台写本地文件。报告保留设备、实例、操作/任务快照、
开始/结束时间、导出本地时区、桌面/Agent/iperf3 版本、参数、每方向状态、指标、清理状态、
事件、失败原因和完整性。复核只更新结束确认，不将未知过程改写为成功。
保留的客户端原始输出最多每方向 1 MiB，板端日志最多 60000 字节，分别标记截断；
事件累计最多 7 MiB/65536 条，达到上限停止并标记不完整。
原始输出截断与测量解析失败分别记录，报告不承诺保存无限原始日志。

## 验收条件

- 无 Qt 层覆盖白名单/类型/范围、重复操作、迟到启动、所有者/实例错误、旧任务互斥、租约、
  取消/完成竞争、丢失启动响应、停止超时及原任务复核。
- GPIO 分别核对枚举、占用拒绝、as-is、保持/续期、脉冲、输入监听、释放、缺口与不支持路径；
  主机夹具与实际电压/边沿测量分开记录。
- 扩展接口覆盖两类 ABI、低电平不误发切输入、映射/占用者/端点身份变化、只读用途、权限/读回失败、持续设置与旧 Agent；
  Linux 文件系统模拟验证与真实主板只读/输出验证分开记录。
- 网络覆盖双向/单向、TCP/UDP、未就绪/错误端点、路由/网口变化、部分完成、解析与所属进程清理；
  回环结果不能替代双端以太网验证。
- UI 检查无服务、占用、收藏与取消确认、无网口、进行中/结束/未知状态、切页与关闭收尾，
  至少核对 1366×768、1920×1080 和代表高 DPI 快照。
- Windows 与三个 Agent 目标分别构建并校验 Runner；未执行的实机、异常和压力项目写“未验证”。

统一列表还需覆盖旧收藏双备注保留、同物理行去重、占用接口能力缺失/多映射保护、访问方式变化后选择保持，以及数字框鼠标/键盘/边界/禁用态和 100%/125%/150% DPI。
