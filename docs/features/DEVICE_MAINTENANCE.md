# 设备诊断与维护功能契约

[返回产品设计](../PRODUCT.md) · [查看当前状态](../STATUS.md)

## 入口与目标

“ADB 调试 → 远程调试”提供外部 ADB Shell、诊断日志、设备维护和 Android 投屏。
宽窗口采用左右两栏，左侧为 Shell、日志与维护，右侧为投屏；内容宽度不足 980 逻辑像素时上下排列并允许纵向滚动。
布局变化保留会话，不启动任务。所有动作使用当前在线且已授权的 ADB 设备，无需连接板端服务。

一次只执行一个诊断或维护任务。任务有独立 ID，固定设备、动作、目标文件和超时；切换选择不迁移已开始的任务，
结果始终标明原设备。全局后台任务菜单与页面提供对应停止动作，旧 ID 不得取消新任务。

## 日志导出

- Logcat 使用固定 `adb -s <serial> logcat -d`，适用于 Android，保存读取时可见的默认日志缓冲区；不表示全程日志或跨缓冲区的一致性快照。
- 内核日志使用固定 `adb -s <serial> shell -T dmesg`。工具缺失、权限不足或断线须保留具体原因；不自动提权。
- 用户选择本地文件后执行，不增加设备确认框；已有文件的覆盖由保存对话框明确确认。确认期间切换设备会拒绝原操作。
- 标准输出直接流式写入独占创建的同目录 `.partial-<唯一标识>` 文件，不进入 GUI 或受管命令的通用输出缓冲，保留实际字节、NUL 和换行，不自动转码。标准错误单独限额 64 KiB，不混入日志。
- 默认命令超时 30 秒。取消、超时、命令失败、写入或提交错误均不显示导出成功，保留部分文件路径、已写字节与原因。
- 只有命令成功、文件刷盘与提交成功后才显示“日志已导出”。完成时同目录替换目标；未授权覆盖时遇到稍后出现的同名文件失败，原文件保留。
- 日志导出可与已有文件、串口或投屏会话并行；本页的单任务门禁仍生效。日志导出不是持续 Logcat 录制，也不保证变化中的日志一致。

## 显式设备维护

维护前显示原设备、动作及连接影响，默认取消；确认后重新核对设备与活动任务。
同设备的远端文件任务、设备串口、板卡任务、投屏或服务准备会阻止维护；本地文件操作和 Windows COM 独立工作。
维护期间阻止该设备新建文件任务、设备串口连接、投屏和服务准备，暂停全局发现结果的应用，固定设备选择。
进入维护时使旧服务代次失效并清理所属连接；结束后重新发现设备，不沿用旧连接与转发状态。

| 动作 | 执行与结果 |
| --- | --- |
| Root 与 Remount | 先读取 Android SDK 属性，确认后请求 `root`；在默认 60 秒内针对原设备反复读取 `id -u`，仅 UID 为 0 才执行 `remount`。Root 拒绝或身份未核验不进入挂载步骤。分别记录 Root、身份与挂载结果；Remount 失败或返回不明确显示部分完成。只有明确成功响应才记为命令接受成功，仍不等于所有分区可写 |
| 重启设备 | 确认后发送 `reboot`，分别显示命令请求、原设备 ADB 离线与重新上线。默认 60 秒内未观察到完整过程则报告等待超时；ADB 在线不证明系统启动完成；客户端自身的错误不计为设备离线证据 |
| 重启至 Loader | 仅对本地已有 BSP/实机依据确认的目标开放，使用固定 `reboot loader`。ADB 离线只说明失去 ADB，不能证明 Loader；需要 USB 枚举或实机证据。当前默认没有已核实目标，因此入口隐藏，不按型号名称推断支持 |

`root` 可能重启 adbd；Remount 可能受构建类型、verity 或 OverlayFS 限制。
Remount 明确返回成功并同时要求重启时，分别记录“命令返回成功”和“部分设置需手动重启生效”，总体保留部分完成；仅有 OverlayFS 准备/重启提示时，不当作 Remount 已成功。结果区保留实际输出，不因为包含 `reboot` 一词就吞掉明确的成功响应。
首版不自动追加 `disable-verity`、`remount -R`、重启或其他补救命令，详情保留实际响应供用户判断。
停止只取消后续步骤或等待，不能撤销已经发出的 Root、挂载或重启请求，不能宣称回滚。

## 分层、退出与验收

`DeviceMaintenanceService` 在无 Qt 层管理请求校验、固定任务快照、冲突、取消与结果。
`IDeviceMaintenanceBackend` 只暴露固定动作；桌面 ADB 适配器执行命令、流式文件和有界恢复等待。
Qt 面板处理选择、确认、异步调度和展示，后台任务不访问控件。不是任意命令输入，也不扩展 Agent shell RPC。

关闭窗口先取消并等待本工具拥有的任务与文件写入收尾，界面继续处理事件；只终止所属 ADB 客户端，
不关闭共享 ADB server 或用户终端。单个主机文件系统调用不承诺硬超时，坏盘、网络路径可能延迟写入及退出。
工具不能阻止其他程序同时修改设备或文件，不能撤销外部操作。

必要验收包括：设备/路径/动作校验、固定设备和任务 ID、单任务及同设备冲突、取消前不执行、
大于通用输出限额的精确字节导出、原文件保护、权限失败/部分文件、输出回调失败、Root 身份核验、
Root 与挂载部分完成、重启各阶段、确认期间设备变化、布局切换和活动任务退出。
假后端、原生模拟 ADB、真实板卡、物理断线和长时结果分别记录在 STATUS，不能互相替代。
