# 串口终端功能契约

[返回串口工作台](SERIAL.md) · [查看当前状态](../STATUS.md)

入口为左侧“串口调试 → 串口终端”，独立页面和会话，沿用公共连接栏；顶部不重复提供模式页签。

## 1. 使用任务

通过开发板 Debug 串口查看启动日志、进入 U-Boot 或 Linux Shell，在 ADB 未就绪时继续排障。
左侧“串口调试”展开三个子入口；终端拥有独立的连接、参数、计数、发送队列及显示缓冲。
来源、波特率或模式不会根据串口名称暗中改变。Agent 不增加 shell RPC。

## 2. 连接与切换

- 单/双串口调试与终端之间切页保留各自连接和显示，不自动打开或迁移串口、不自动发送数据；终端接收不进入普通收发记录。
- 同一 PC端串口只允许一个页面占用，失败提示占用页面；设备串口按当前协议保持每台 Agent 一个活动会话。占用在异步关闭完成或连接失败处理完成后释放，系统/Agent 仍是最终权限与占用裁决者。
- 单/双串口调试内部仍保留活动端点 A 和运行任务的切换保护；切入独立终端页不隐藏、停止或迁移这些后台任务。
- 终端偏好保存于 `terminal-preferences.json`。首次没有该文件时读取旧通道 B 配置一次，随后与普通调试的偏好分别保存。
- 终端接收连续 RX，UTF-8 和转义序列允许跨接收批次；普通监视器继续独立记录各次接收，二者不使用时间拼接。
- 本地串口收到 RX 事件即交付数据，最少 1 字节即可通知；不等待接收空闲、回车或下一批数据才显示。
  CSerialPort 使用 `setReadIntervalTimeout(0)` 的事件通知路径，GUI 的短周期绘制独立于数据交付。
- 终端仅展示板端输出，不添加本地 TX 回显；成功发送仍计入会话字节计数和持续录制中的 TX，不插入终端网格。
- 新连接和断开结束上次的半个 UTF-8/ANSI 序列，保留既有可见输出。连接状态和发送失败显示在连接条。
- 连接条的状态标签与按钮分别呈现；服务未就绪提示内联在连接动作处。终端去除重复外层卡片，服务提示显隐不挤动日志区；详细视觉规则见 [界面设计](../UI_DESIGN.md)。
- PC端串口不依赖 ADB 或 Agent；刷新仅枚举 PC 端列表，设备扫描和维护不阻止空闲 PC 端点刷新。名称、刷新与端口草稿规则同 [串口工作台](SERIAL.md)。端口被占用时提示先断开其他终端中的该串口，不强制关闭其他程序。

## 3. 输入、复制与粘贴

进入页面、连接成功或关闭搜索后聚焦终端；没有连接时不发送。只有板端回显才显示输入，历史、编辑、补全由板端拥有。GUI 只提交有界异步队列。

| 操作 | 行为 |
| --- | --- |
| Enter / Backspace | 默认 CR / DEL（7F），选项中可改 LF、CRLF / BS（08）；独立于普通调试行尾 |
| Ctrl+C | 默认有非空选区时复制并清除选区，不发送；无选区发送 03 |
| Ctrl+V | 默认粘贴；关闭“智能 Ctrl+C / Ctrl+V”后两键始终发送 03 / 16 |
| Ctrl+Shift+C / V、Shift+Insert | 始终复制 / 粘贴；复制不发送 |
| Ctrl+A…Z | 除上述本地快捷键外发送对应控制字节；Ctrl+L 为 0C，不自动清屏 |
| 方向、Home/End、Insert/Delete、PageUp/Down、F1…F12、Tab | 由引擎按设备的普通/应用光标模式及 Shift/Alt/Ctrl 修饰编码 |
| Ctrl+Shift+F、F3 / Shift+F3 | 搜索、下一个 / 上一个匹配，保持行布局 |
| Shift+PageUp / PageDown | 本地回看，不发送 |

- 拖选字符、双击选词、三击选行；Alt+拖动矩形选择。启用鼠标报告后，普通鼠标动作交给设备，按住 Shift 进行本地选择。
- 复制软折行时还原连续长行，硬换行保留换行；矩形按列保留各行。历史淘汰或尺寸重排使原位置失效时清除选区，不复制错位内容。
- 选区或离开底部时暂停跟随；下一次输入清除选区、关闭搜索并回到实时光标。回看状态不影响普通调试偏好。
- 可开启“选中即复制”“无选区时右键粘贴”；默认关闭。右键菜单保留复制、粘贴与回到最新输出，强制中断在终端选项中。
- 多行粘贴先显示行数与前五行预览，默认取消；可选择本次连接不再提示。确认后再核对连接代次。CR/LF/CRLF 转为所选行尾，不追加换行；移除 ESC、NUL 等控制字符（保留 TAB 与换行）。设备启用 `?2004h` 时使用 bracketed paste 包裹。
- 输入法预编辑只画在本地光标处；提交时发送 UTF-8。候选窗使用实际网格光标矩形，不把预编辑写入接收历史。

## 4. 字符网格与兼容范围

- 采用固定源码的 libvterm 0.3.3；支持主/备用屏幕、光标寻址、滚动区域、擦除、UTF-8、宽字符与组合字符。主屏回看与备用屏独立，退出备用屏恢复主屏。
- ANSI 16/256 色、TrueColor、粗体、斜体、下划线、反色、删除线按单元格绘制；CJK 宽字符占两列。框线与块元素使用几何绘制；光标支持块、竖线、下划线，失焦为空心框。
- “终端外观”提供柔和深色、暖白浅色、高对比、等宽字体、11–18 px 字号（默认 15）和 0–6 px 额外行距（默认 3），以及跟随设备/固定光标形状。设置与智能按键、鼠标偏好保存在 `terminal-preferences.json`。0.15.0 的原始默认 14 px / 行距 2 仅升级一次为 15 / 3，定制值及之后明确保存的 14 / 2 保留。
- 网格限制为 2–256 行、8–512 列；标题行显示“列 × 行”。UART 没有带外尺寸通知，缩放不发送 Shell 命令；“复制窗口尺寸命令”只复制 `stty rows R cols C`，用户决定何时执行。
- 主屏历史默认最多 20000 行，同时最多 1048576 字符单元（以先到者为准）。缩放重排保留的历史和活动屏幕；上游回填接口不能表达软折行元数据，重排时将相关历史保留在回看区，避免截掉宽行右半部分。
- `CSI 2J` 清活动屏幕，`CSI 3J` 清回看；不把所有擦除视作本地“清屏”。本地清屏重置网格/回看与解析状态，保留计数和持续录制；Ctrl+L 始终是发送动作。
- 固定 VT 查询（例如光标位置、设备属性）由引擎产生协议应答，并经过当前代次的会话发送队列。它们不包含 Shell 命令；不执行 OSC 52 剪贴板、标题/进程或任意 Shell 回调。
- 搜索最多保留 10000 个匹配，覆盖当前保留的主屏历史或备用屏；不提供“只看匹配”。自动高亮按固定错误/警告词持续匹配，新配置默认开启；已明确保存的关闭状态保留，可随时关闭。高亮和搜索为只读覆盖，选区优先；关闭后恢复 ANSI，不修改原始数据。
- 接收时间放在独立、较淡的边栏，不占板端列位置，表示保留文字行最近一次文本变化的主机接收时间。空白行不显示；未连接空屏、只发送未回显、清屏、窗口变化和纯光标移动不生成时间。保存日志导出保留的文本，合并软折行，不包含时间边栏或 ANSI 控制字节；需要原始数据使用录制。

完整 xterm 兼容性和每个固件上的 vim/top/htop/menuconfig 均须分别验证，不由引入库或主机回放推定通过。

## 5. 后台解析与录制

- `SerialSession` 先把原始 RX 交给独立录制，再投递给 `application/terminal/terminal_engine.*`。录制规则见 [串口契约](SERIAL.md#29-持续录制与关键字高亮)。
- 单个后台线程按序处理 RX、输入、尺寸及重置。解析队列默认 1 MiB、2048 个 RX/普通命令，并保留 64 个控制命令空间。溢出丢弃新片段、按顺序标记缺口、计数并重置解析；输入拒绝单独计数提示。录制是否完整以其独立结果为准。
- 快照不可变，未变行共享引用；GUI 不调用 VT 解析或等待工作线程，只读取最新快照并绘制可见脏行。可见行按内容、外观和实际 DPR 缓存像素，只保留当前可见范围；选区、搜索和光标独立叠加，字体/配色/尺寸/DPR 变化使缓存失效。空选区按键不触发整屏重画，空白字符不执行文本整形；字形布局按四种字体样式各保留最多 512 个字符簇，复用字体回退和组合字符布局，字体/DPR 改变时失效。显式输入后 150 ms 内的首次接收更新可立即绘制，以减少逐字回显的显示等待；不据此判断接收文本是否是设备对该输入的应答。后台最多约 8 ms 合并，GUI 通知合并后直接读取最新帧，不再另等一个 16 ms 定时周期；跳过中间显示帧不会跳过解析字节，空闲无解析/渲染轮询（焦点光标闪烁独立）。
- 清屏、搜索、回看、颜色和历史限额不改变录制。断线/新连接终止半个 UTF-8/控制序列，保留已显示内容；旧代次输入、接收和查询应答不能进入后续连接。
- 连接、录制、端口登记与异步关闭仍复用 `SerialEndpointWorkspace`，普通调试继续使用文本接收视图，终端实际不创建 `QPlainTextEdit`。

## 6. 验收

| 场景 | 最低条件 |
| --- | --- |
| VT 核心 | 备用屏恢复、滚动区边界、分片 UTF-8/宽字符/组合字符、颜色、模式按键、软折行与重排、有界历史/队列、旧代次隔离 |
| 界面输入 | 智能/传统 Ctrl+C/V、Tab 不切焦点、修饰键不清选区、复制和多行预览无误发、IME 预编辑/提交和光标矩形 |
| 显示 | 搜索和高亮保留源样式，清屏不影响录制；1366×768、1920×1080 与代表高 DPI/窄窗无控件重叠 |
| 独立性 | 页面切换保留会话，同口拒绝且异步关闭后可交接；普通发送、快捷指令、计划发送和双端测试不受终端偏好影响 |
| 交互与性能 | 以相同主机/尺寸/DPR 比较模拟按键到写入、解析快照和绘制完成的 P50/P95/最大值，事件泵不得用休眠轮询制造采样延迟。分别记录无 RX 空屏、保留文字后的输入/重绘/切页，以及持续回放；标明 Debug/Release、DPR、模拟发送与板端回显的边界。回放记录速率/时长、字节数、帧数、GUI 响应、绘制耗时和内存；不使用“零卡顿”作为结论 |
| 实机 | 另记真实 Debug 串口逐字回显、输入法、补全/中断、全屏程序、断线和长时高波特率；主机夹具与打开端口不能替代这些结果 |
