# 串口终端功能契约

[返回串口工作台](SERIAL.md) · [查看当前状态](../STATUS.md)

入口为左侧“串口调试 → 串口终端”，独立页面和会话，沿用公共连接栏；顶部不重复提供模式页签。

## 1. 使用任务

通过开发板 Debug 串口查看启动日志、进入 U-Boot 或 Linux Shell，在 ADB 未就绪时继续排障。
左侧“串口调试”展开三个子入口；终端拥有独立的连接、参数、计数、发送队列及显示缓冲。
来源、波特率或模式不会根据串口名称暗中改变。Agent 不增加 shell RPC。

## 2. 连接与切换

- 单/双串口调试与终端之间切页保留各自连接和显示，不自动打开或迁移串口、不自动发送数据；终端接收不进入普通收发记录。
- 同一 PC端串口只允许一个页面占用，失败提示占用页面；设备串口按当前协议保持每台 Agent 一个活动会话。占用在异步关闭完成或连接失败收敛后释放，系统/Agent 仍是最终权限与占用裁决者。
- 单/双串口调试内部仍保留活动端点 A 和运行任务的切换保护；切入独立终端页不隐藏、停止或迁移这些后台任务。
- 终端偏好保存于 `terminal-preferences.json`。首次没有该文件时读取旧通道 B 配置一次，随后与普通调试的偏好分别保存。
- 终端接收连续 RX，UTF-8 和转义序列允许跨接收批次；普通监视器继续独立记录各次接收，二者不使用时间拼接。
- 本地串口收到 RX 事件即交付数据，最少 1 字节即可通知；不等待接收空闲、回车或下一批数据才显示。
  CSerialPort 使用 `setReadIntervalTimeout(0)` 的事件通知路径，GUI 的短周期绘制独立于数据交付。
- 终端仅展示板端输出，不添加本地 TX 回显；成功发送仍计入字节计数和普通监视器 TX 记录。
- 新连接和断开结束上次的半个 UTF-8/ANSI 序列，保留既有可见输出。连接状态和发送失败显示在连接条。
- 连接条的状态标签与按钮分别呈现；服务未就绪提示内联在连接动作处。终端去除重复外层卡片，服务提示显隐不挤动日志区；详细视觉规则见 [界面设计](../UI_DESIGN.md)。
- PC端串口不依赖 ADB 或 Agent；刷新仅枚举 PC 端列表，设备扫描和维护不阻止空闲 PC 端点刷新。名称、刷新与端口草稿规则同 [串口工作台](SERIAL.md)。端口被占用时提示先断开其他终端中的该串口，不强制关闭其他程序。

## 3. 直接键盘输入

进入终端模式、连接成功或关闭搜索后聚焦终端，直接发送 UTF-8 输入。终端不提供底部命令框、
本地命令历史或常驻快捷指令/中断按钮；历史、编辑和补全由板端处理。没有连接时不得写入串口。
控件只提交有界异步发送队列，不在 GUI 线程等待设备写入。

| 操作 | 实际行为 |
| --- | --- |
| Enter | 使用终端行尾（默认 CR，可选 LF/CRLF） |
| Tab | 发送 `09`，由板端补全 |
| Ctrl+C | 始终发送 `03`，包括有选区时；通常用于中断板端前台命令，不负责停止内核日志或断开串口 |
| Ctrl+Shift+C | 复制选中文本，不发送字节 |
| Ctrl+D / Ctrl+L | 分别发送 `04` / `0C`；Ctrl+L 等待板端重绘，不额外清空本地输出 |
| ↑/↓/←/→ | 终端区域发送对应 ANSI 方向键，由板端处理历史/光标 |
| Backspace / Delete | 默认分别发送 `7F` / `ESC [ 3 ~`；Backspace 可在菜单改为 `08` |
| Home/End、PageUp/PageDown、Esc | 发送对应终端键码；搜索展开时 Esc 优先关闭搜索 |
| Ctrl+Shift+V / Shift+Insert | 粘贴到板端，CR/LF/CRLF 统一转换为所选终端行尾，不额外追加回车 |
| Ctrl+A…Z | 发送对应控制字节，例如 Ctrl+F 为 `06`、Ctrl+V 为 `16`，交给板端行编辑器 |
| Ctrl+Shift+F / F3 | 打开搜索 / 下一个匹配，不发送字节 |
| Shift+PageUp / Shift+PageDown | 本地回看输出，不向板端发送翻页键 |

右键菜单提供复制、粘贴和中断。滚轮或滚动条离开底部时暂停跟随，回到底部恢复；选中文本期间
新输出不把视图拉回底部。下一次设备输入关闭搜索、清除选区并回到实时光标。
终端的临时回看状态不覆盖普通监视器保存的自动滚动偏好。

“终端选项…”集中提供回车格式、Backspace 格式、时间戳、跟随输出、计数清零和按键说明。
终端行尾、Backspace 独立保存在串口偏好中，旧文件缺失时分别默认 CR、DEL（`7F`）；
普通手动/AT 发送的共享行尾和快捷指令栏仍属于普通调试模式。

## 4. 输出与显示

- 标题栏提供“录制…”与“高亮”，格式、队列和生命周期统一见 [串口录制契约](SERIAL.md#29-持续录制与关键字高亮)。
  录制保存解析前的会话数据，清屏与 ANSI 擦除不会修改录制文件；文本录制中的 TX 仍可与屏幕的仅 RX 输出区分。
- 显示积压与全局停止入口见 [显示积压与后台任务](SERIAL.md#210-显示积压与后台任务)。发生显示缺口时重置解析流，保留可见历史并提示截断。
  关键字格式是只读叠加，搜索优先，关闭后恢复原有 ANSI 颜色；不触发终端输入。

- 解析 CR 行首覆盖、LF 换行、BS 退格、8 列 TAB，以及常用 CSI 光标移动/定位、行尾擦除、保存恢复光标。
- SGR 支持普通/亮色前景背景、256 色、RGB、粗体、下划线和反色，序列跨批次时仍能继续解析。
- 完整 UTF-8 正常显示；非法编码或连接结束时未完成的字符显示替代字符。终端不插入每批 RX 的方向前缀。
- CSI `J` 的 2/3 清空当前终端输出视图并回到起点；普通原始收发缓冲不受影响。它是启动日志/Shell 控制台，
  没有独立固定行列屏幕、备用屏幕、滚动区域或完整字符宽度表；不据此宣称兼容 vim/top 等全屏 TUI。
- 未实现的完整 CSI 会被消费；OSC/DCS 等字符串控制序列会有界忽略，不处理标题、剪贴板或终端查询应答。
- 最多保留 10000 行/1M 字符单元，每行最多 4096 单元，超长行续行；淘汰最早内容时提示“已截断”。
- UI 按约 16ms 周期合并刷新，替换变化部分；淘汰旧行时增量删除对应文档块，保留未变化历史。清屏、显示设置变化或积压超过现存文档时可重建；不按刷新周期拼接普通日志。
  单独的 BS、CR 或 CSI 光标移动也会刷新光标；闪烁光标独立于文本选区，点击或拖选不改变板端光标位置。
- 搜索保留完整行布局，只做匹配导航；终端不提供“只看匹配”，避免破坏屏幕行号与光标映射。
  时间戳标注该行首次出现文字的接收时间，保存当前渲染文本；显示开关不向板端发送数据。
- “清屏”只清当前终端视图，保留计数和普通监视器记录；“计数清零”保留两种视图。Ctrl+L 具有发送语义。

常用序列参考 [XTerm Control Sequences](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html)；
本节明确列出的子集是本产品契约，不以完整 xterm 兼容性作为验收要求。

## 5. 分层与验收

`application/serial/serial_terminal.*` 拥有无 Qt 的解析、显示单元、限额和键码；Qt 页面拥有焦点、
输入法桥接、样式和定时重绘。发送仍经过 `SerialSession`，接收回调排入 GUI 后核对会话代次。

| 场景 | 最低验收 |
| --- | --- |
| 独立连接 | 终端和普通调试有独立状态、参数、计数和 RX；切页不断开、不额外发送；同口拒绝且关闭后可交接 |
| 启动日志 | UTF-8、ANSI 每个字节拆开接收也保持解析结果；CR 进度覆盖、BS、清行可用 |
| 逐字回显 | 在启用回显的真实 Shell 中分别输入 l、s，不按 Enter 也能看到两个字符；同时记录发送、接收和显示，不能只用假串口验证 |
| 交互按键 | Tab/控制键/方向键/Enter 实际字节正确；Ctrl+C 始终中断，Ctrl+Shift+C 复制无发送，粘贴行尾一致 |
| 焦点与光标 | 进入/连接后直接输入；纯光标序列可见；选区与回看不修改板端光标，继续输入恢复实时位置 |
| 搜索与导出 | 搜索保留行布局，不阻塞原始流解析；保存当前渲染文本 |
| 录制与高亮 | 清屏、ANSI 擦除与显示限额不改动录制；关键词和搜索叠加只改样式；停止与退出确定保存已接受字节 |
| 异常与限额 | 断线不接受发送，旧回调不能覆盖新连接；清空、重连、万行截断后解析和显示继续可用；增量文档与缓冲一致 |
| 目标窗口 | 1366×768、1920×1080 下连接栏、终端、选项菜单和搜索不重叠，普通发送区与快捷指令隐藏 |
| 实机 | 单独记录 Debug 串口启动日志、U-Boot/Linux 补全、中断、历史与断线；主机夹具不代表实机通过 |
